# 总包工程款一揽子和解及以房抵债协议要点

**适用：** 工程款约 5,800 万元，债权人集中为施工总包一家；存货为现房且可办证；无银行抵押。

本文为谈判与起草提纲，供律师据此出具正式合同。

---

## 一、协议目标

一次签约，完整化解开发商对总包的全部工程款债务（含已确定及可预见争议款项），实现：

1. 总包停诉、停执、撤查封；  
2. 开发商交付可过户现房完成主要清偿；  
3. 少量现金头款 + 短分期收口剩余债权；  
4. 总包内部消化分包、材料商及农民工工资，阻断重复追索。

---

## 二、建议交易结构（开口条件）

| 项目 | 建议安排 |
| --- | --- |
| 确认债权总额 | 【5,800】万元（或“暂定【 】万，结算审定后多退少补，差额以增减房源调整，幅度不超过【3%】”） |
| 以房抵债 | 【5,200—5,800】万元（附房源清单为协议附件；**零现金情形下尽量抵满**） |
| 现金头款 | **0**（公司现无货币资金；若总包坚持，改为“有共管回款再付”，不设签约即付） |
| 配套费代垫 | 总包可代垫拟过户房屋对应城建配套费，并在抵债价款中等额扣减 |
| 留债分期 | 【0—400】万元，有销售回款后再从共管账户划付 |
| 抵债单价 | 零现金下可谈到市场价【80%—90%】，以价格换取免现金头款 |
| 过户时点 | 住建局同意随过户缴纳后【30—60】日内启动；第一批优先总包房源 |

---

## 三、必须条款清单

### 1. 主体与范围

- 甲方：开发商（债务人）  
- 乙方：施工总包（唯一工程款债权人）  
- 如有项目公司与集团双主体欠款，一并列为共同债务人，避免漏网  
- 明确本协议覆盖：合同价、签证、索赔、违约金、利息、诉讼费等全部工程相关主张

### 2. 债权确认

- 列明施工合同、补充协议、已付款、已扣款、质保金  
- 采用“确认额”或“暂定额 + 审价调整”二选一  
- 质保金：可保留【3%—5%】至质保期满，或折价并入抵债总额

### 3. 以房抵债

- 附件列明：楼栋房号、面积、用途、拟过户权利人（总包或其指定关联方）  
- 抵债价格、价税分离、发票与会计处理约定  
- 房屋现状：现房交付，按现状交接，质量问题按质保条款处理  
- 禁止总包在过户前再行抵押、转售冲突处置  
- 若某套房因查封等无法过户：等值替换房源或改现金

### 4. 零现金结构、代垫配套费与共管

- **不设签约现金头款**；总包以停诉停执换取优先选房、优惠抵债价、优先过户  
- 总包代垫单套城建配套费的，开发商开具收据/确认函，并在该套抵债价中扣减  
- 若后续出现第三方销售回款，进入共管账户，划付顺序：该套城建配套费 → 约定留债（如有）→ 其他  
- 详细零现金路径见：`docs/零现金启动化债路径.md`

### 5. 停诉停执与优先权

- 已立案案件：限期内撤诉或申请中止  
- 已查封房产：配合解除，保障抵债与销售  
- 约定：在本协议对价履行完毕前，乙方不得就同一债权申请拍卖；对价履行完毕后，优先受偿权随债权消灭

### 6. 分包、材料商、农民工（核心风控）

总包作出承诺与补偿：

1. 自行清偿其分包商、材料商、劳务工人等款项；  
2. 若前述第三方起诉开发商或查封项目资产，总包应在【X】日内排除妨碍，并赔偿开发商损失；  
3. 开发商有权从应付留债/未过户房源中扣抵。

> 单一总包结构下，这一条必须强硬写入，否则“一揽子”会被分包二次捅破。

### 7. 办证与税费

- 开发商负责：具备办证条件的手续推进、协助网签/不动产登记  
- 总包负责：购房资格（如需）、接收方主体合规、约定税费  
- 城市建设配套费由开发商按与**住建局**的安排缴纳或分期/随过户缴纳；因该费用缴费路径未落实导致延误过户的，顺延过户期限但不视为开发商根本违约（需限合理期间）

### 8. 生效与解除

- 生效条件：双方法定代表人签署 +（可选）总包内部有权机关批准  
- 解除条件：持续无法办证超过【90】日、总包违反停诉承诺、开发商拒不配合过户等  
- 解除后的返还与债权恢复安排

### 9. 违约责任

- 总包再行查封/拍卖：支付违约金【 】万，并赔偿房价贬损、融资损失  
- 开发商逾期交付可过户房产：按日违约金或增加等值房源  
- 争议解决：项目所在地法院 / 约定仲裁

## 四、谈判话术（零现金版）

1. **“公司账上完全没有现金，再谈现金头款只会拖死过户；现在能给你的是现房优先选房权。”**  
2. **“单价可以让到市场价八至九折，用价格换你接受零现金。”**  
3. **“单套城建配套费你可先垫，我在抵债价里扣——你垫的是过户门票，不是给我输血。”**  
4. **“现房无抵押，签完就能往过户走；拍卖要时间、要折价，还要跟其他执行挤。”**  
5. **“分包农民工必须你收口。你若坚持全额现金并查封，我们只能转预重整，你未必拿得更多。”**

---

## 五、签约前开发商内部准备清单

1. 可抵债房源清单（建议货值 4,500—5,500 万，留替换余量）；  
2. 工程合同、付款台账、结算资料；  
3. 诉讼/查封清单；  
4. 住建局关于城建配套费分期或随过户缴纳的书面意见 / 会议纪要；  
5. 共管账户开立方案；  
6. 首笔现金头款来源（应收按揭或急售回款）；  
7. 律师出具的正式合同文本与用印审批。

---

## 六、签约后 30 日执行顺序

1. 总包提交撤诉/中止/解封申请；  
2. 开发商支付现金头款；  
3. 双方完成房源交接清单签认；  
4. 住建局城建配套费路径落地后启动首批过户；  
5. 留债分期进入共管账户自动划付；  
6. 全部过户完成后签《债务清偿确认书》。
