# 总包工程款一揽子和解及以房抵债协议要点

**适用：** 工程款约 5,800 万元，债权人集中为施工总包一家；存货为现房且可办证；无银行抵押。

本文为谈判与起草提纲，供律师据此出具正式合同。

---

## 一、协议目标

一次签约，完整化解开发商对总包的全部工程款债务（含已确定及可预见争议款项），实现：

1. 总包停诉、停执、撤查封；  
2. 开发商交付可过户现房完成主要清偿；  
3. 少量现金头款 + 短分期收口剩余债权；  
4. 总包内部消化分包、材料商及农民工工资，阻断重复追索。

---

## 二、建议交易结构（开口条件）

| 项目 | 建议安排 |
| --- | --- |
| 确认债权总额 | 【5,800】万元（或“暂定【 】万，结算审定后多退少补，差额以现金/增减房源调整，幅度不超过【3%】”） |
| 以房抵债 | 【4,500—5,200】万元（附房源清单为协议附件） |
| 现金头款 | 【300—500】万元，签约后【15—30】日内支付至总包指定账户 |
| 留债分期 | 【300—800】万元，分【12—18】个月，每月/每季度从销售共管账户划付 |
| 抵债单价 | 按同项目近期网签均价或评估价的【90%—95%】协商 |
| 过户时点 | 配套费办证通道打通后【30—60】日内启动批量过户；可分两批 |

---

## 三、必须条款清单

### 1. 主体与范围

- 甲方：开发商（债务人）  
- 乙方：施工总包（唯一工程款债权人）  
- 如有项目公司与集团双主体欠款，一并列为共同债务人，避免漏网  
- 明确本协议覆盖：合同价、签证、索赔、违约金、利息、诉讼费等全部工程相关主张

### 2. 债权确认

- 列明施工合同、补充协议、已付款、已扣款、质保金  
- 采用“确认额”或“暂定额 + 审价调整”二选一  
- 质保金：可保留【3%—5%】至质保期满，或折价并入抵债总额

### 3. 以房抵债

- 附件列明：楼栋房号、面积、用途、拟过户权利人（总包或其指定关联方）  
- 抵债价格、价税分离、发票与会计处理约定  
- 房屋现状：现房交付，按现状交接，质量问题按质保条款处理  
- 禁止总包在过户前再行抵押、转售冲突处置  
- 若某套房因查封等无法过户：等值替换房源或改现金

### 4. 现金头款与共管

- 头款支付条件：协议生效 + 总包提交撤诉/中止执行申请材料  
- 销售回款进入共管账户，划付顺序写死：必要办证费用 → 本协议分期款 → 其他

### 5. 停诉停执与优先权

- 已立案案件：限期内撤诉或申请中止  
- 已查封房产：配合解除，保障抵债与销售  
- 约定：在本协议对价履行完毕前，乙方不得就同一债权申请拍卖；对价履行完毕后，优先受偿权随债权消灭

### 6. 分包、材料商、农民工（核心风控）

总包作出承诺与补偿：

1. 自行清偿其分包商、材料商、劳务工人等款项；  
2. 若前述第三方起诉开发商或查封项目资产，总包应在【X】日内排除妨碍，并赔偿开发商损失；  
3. 开发商有权从应付留债/未过户房源中扣抵。

> 单一总包结构下，这一条必须强硬写入，否则“一揽子”会被分包二次捅破。

### 7. 办证与税费

- 开发商负责：具备办证条件的手续推进、协助网签/不动产登记  
- 总包负责：购房资格（如需）、接收方主体合规、约定税费  
- 配套费由开发商按与征收机关的安排缴纳或分期；因配套费延误过户的，顺延过户期限但不视为开发商根本违约（需限合理期间）

### 8. 生效与解除

- 生效条件：双方法定代表人签署 +（可选）总包内部有权机关批准  
- 解除条件：头款逾期、持续无法办证超过【90】日、总包违反停诉承诺等  
- 解除后的返还与债权恢复安排

### 9. 违约责任

- 总包再行查封/拍卖：支付违约金【 】万，并赔偿房价贬损、融资损失  
- 开发商逾期交付可过户房产：按日违约金或增加等值房源/现金  
- 争议解决：项目所在地法院 / 约定仲裁

---

## 四、谈判话术（给开发商）

1. **“就你一家，方案可以按你的回款和拿房需求定制，不会被其他工程债权人摊薄。”**  
2. **“现房、无抵押、可办证，现在签约过户，比起诉拍卖快一年以上，折价也更小。”**  
3. **“头款现金 + 大头现房 + 短分期，是目前流动性下能给到的最高诚意。”**  
4. **“分包和农民工必须你内部收口；你不收口，房也过不了户，大家一起死磕。”**  
5. **“若拒绝抵房坚持全额现金，公司只能走预重整/重整，你的受偿未必更好，时间一定更长。”**

---

## 五、签约前开发商内部准备清单

1. 可抵债房源清单（建议货值 4,500—5,500 万，留替换余量）；  
2. 工程合同、付款台账、结算资料；  
3. 诉讼/查封清单；  
4. 配套费缴纳或分期书面意见；  
5. 共管账户开立方案；  
6. 首笔现金头款来源（应收按揭或急售回款）；  
7. 律师出具的正式合同文本与用印审批。

---

## 六、签约后 30 日执行顺序

1. 总包提交撤诉/中止/解封申请；  
2. 开发商支付现金头款；  
3. 双方完成房源交接清单签认；  
4. 配套费路径落地后启动首批过户；  
5. 留债分期进入共管账户自动划付；  
6. 全部过户完成后签《债务清偿确认书》。
