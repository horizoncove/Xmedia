## 一、前言与编制说明

### 1.1 编制目的

为妥善化解【公司名称】（以下简称“本公司”或“债务人”）及【纳入预重整范围的关联企业清单，如有】（合称“预重整企业”）面临的流动性危机与债务风险，在地方政府协调、人民法院指导及主要债权人支持下，通过预重整程序提前梳理资产负债、协商债务清偿安排、推进保交楼与资产盘活，并在条件成熟时有序转入正式重整程序，特编制本《预重整方案》（以下简称“本方案”）。

### 1.2 编制依据

本方案主要依据下列法律、政策及文件编制：

1. 《中华人民共和国企业破产法》及相关司法解释；
2. 《中华人民共和国民法典》；
3. 《最高人民法院关于适用〈中华人民共和国企业破产法〉若干问题的规定》等司法文件；
4. 关于预重整、府院联动、保交楼、房地产融资协调等地方实践及政策文件；
5. 【受理法院 / 属地中院】关于预重整工作的相关指导意见或工作指引；
6. 本公司及纳入范围企业的工商登记资料、财务报表、项目资料及债权人沟通成果。

### 1.3 编制原则

1. **依法合规原则**：严格遵循破产法及相关规定，保障各方合法权益；
2. **府院联动原则**：在属地政府协调与人民法院指导下推进；
3. **保交楼优先原则**：优先保障已售未交付商品房项目顺利竣工交付；
4. **公平清偿原则**：同类债权同等对待，依法确定清偿顺序；
5. **市场化、法治化原则**：通过市场化谈判、引入投资、资产处置等方式化解风险；
6. **整体协同原则**：统筹项目公司、集团总部及关键担保链条，避免割裂处置；
7. **节约成本、提高效率原则**：通过预重整缩短正式重整周期、降低程序成本。

### 1.4 重要提示

1. 本方案为预重整阶段协商文本，相关安排需经主要债权人协商确认，并在转入正式重整后依法提请债权人会议表决、人民法院裁定批准后生效实施。
2. 文中财务数据、债权数额、资产估值、清偿比例等均为【截至基准日的测算数 / 暂估数】，最终以审计、评估、债权确认结果为准。
3. 未特别说明的“元”均指人民币元。

### 2.4 陷入困境的主要原因

1. **流动性错配**：现房货值较高且可办证，但现金不足以同时兑付工程款与配套费；
2. **回款沉淀**：按揭放款、购房尾款等应收账款回收不及预期；
3. **债务结构集中**：工程款占比高，若对立诉讼/拍卖将冲击整体去化；
4. **办证卡点**：欠付住建局城建配套费可能阻碍过户，进而阻断以房抵债与销售交割；
5. **缺乏统一偿债安排**：尚未形成“办证—抵债—销售—清小债”的一体化方案。

## 三、预重整的必要性与可行性

### 3.1 必要性

1. **债务集中到期，常规展期难以根本化解**；
2. **在建项目停工风险上升，保交楼任务紧迫**；
3. **债权人结构复杂，需统一协商平台**；
4. **若直接清算，资产贬损大、购房人及职工利益受损严重**；
5. **预重整可提前锁定重组框架，提高后续正式重整成功率**。

### 3.2 可行性

1. **具备营运价值**：核心项目区位较好，完成续建后可变现或交付；
2. **主要债权人有协商基础**：金融机构债权人已形成初步沟通机制；
3. **地方政府支持**：属地已建立房地产风险化解 / 保交楼协调机制；
4. **可引入增量资金**：存量资产具备吸引央企/国企/AMC/产业投资人的条件；
5. **法律路径清晰**：预重整成果可依法衔接正式重整程序。

### 3.3 预重整目标

1. 稳定项目续建与交付，最大限度保障购房人合法权益；
2. 全面摸清资产负债与担保结构，形成可执行的重组框架；
3. 分类化解金融债权、经营债权、购房人债权等；
4. 优化股权与治理结构，引入战略投资人；
5. 在协商一致基础上，尽快转入正式重整并落地实施。

## 四、预重整工作机制与程序安排

### 4.1 工作组织

建议设立以下工作机制：

1. **府院联动专班**：由属地政府相关部门、人民法院、金融监管部门等组成，统筹维稳、协调与程序指导；
2. **预重整临时管理机构 / 临时管理人**：可由【拟指定的律师事务所 / 清算机构】担任，负责尽调、债权梳理、方案谈判、信息披露等；
3. **债务人工作专班**：由本公司董事长 / 总经理牵头，财务、法务、工程、销售等部门参与；
4. **债权人协商委员会**：由主要金融机构债权人、重要工程债权人代表等组成，对重大事项进行协商；
5. **中介服务机构**：审计、评估、法律、财务顾问等。

### 4.2 预重整期限

建议预重整期限为【3—6】个月，自【启动日 / 法院出具预重整决定或备案内之日】起算；确有必要的，经府院联动专班同意可延长【1—3】个月。

### 4.3 主要工作步骤

| 阶段 | 时间安排 | 主要工作 |
| --- | --- | --- |
| 启动阶段 | 第1—2周 | 明确范围、指定临时管理人、冻结重大资产处置、建立沟通机制 |
| 尽调核查阶段 | 第3—8周 | 审计评估、债权申报梳理、项目排查、诉讼保全梳理 |
| 方案协商阶段 | 第6—16周 | 制定债务重组与经营方案、与各类债权人谈判、引进投资人 |
| 成果固化阶段 | 第14—20周 | 形成预重整协议 / 框架协议、准备转正式重整材料 |
| 程序衔接阶段 | 视进度 | 申请破产重整、提请确认预重整效力、召开债权人会议 |

### 4.4 信息披露与沟通

1. 向主要债权人定期披露项目进度、资金使用、销售回款等情况；
2. 建立购房人、职工、供应商沟通渠道，及时回应关切；
3. 重大事项（资产处置、新融资、担保变更、股权变动等）须经临时管理人及专班同意。

### 4.5 自动中止与保护性安排（协商性）

在预重整期间，争取主要债权人同意：

1. 暂停对核心续建项目资产的强制执行与处置；
2. 暂缓宣布贷款提前到期及交叉违约；
3. 对必要续建融资给予支持或同意资金封闭运作；
4. 诉讼、仲裁、执行程序尽量通过协商或府院联动机制协调处理。

> 注：上述安排不当然产生破产法上的自动中止效力，需以债权人同意、法院指导及后续正式重整裁定为依据。

## 五、债权债务及资产核查安排

### 5.1 债权分类（拟）

结合房地产企业特点，拟按下列类别梳理债权：

1. **有财产担保债权**：土地使用权、在建工程、房产、股权质押等担保债权；
2. **建设工程价款优先受偿权债权**：符合条件的施工承包人工程款；
3. **购房人债权 / 商品房消费者权利**：已支付全部或大部分房款的购房人交付请求权及退款请求权；
4. **职工债权**：工资、社保、补偿金等；
5. **税款债权**；
6. **普通债权**：无担保金融债权、供应商货款、小额债权、诉讼确定债权等；
7. **劣后债权 / 关联方债权**：股东借款、关联往来等，原则上劣后或削减。

### 5.2 债权申报与核查

1. 预重整阶段开展**预申报 / 预登记**，转入正式重整后依法正式申报；
2. 临时管理人组织核对合同、放款凭证、抵押登记、工程进度、裁判文书等；
3. 对争议债权，另行说明并在方案中预留处理机制。

### 5.3 资产清查与评估

资产范围包括但不限于：

1. 存货（开发成本、开发产品）；
2. 投资性房地产与自持物业；
3. 应收款项、预付款项；
4. 子公司股权及对外投资；
5. 货币资金、监管账户资金；
6. 知识产权、品牌及其他无形资产；
7. 未决诉讼中的权利、保险权益等。

评估方法：对续建交付类项目以**假设开发法 / 成本法**为主，对持有型物业以**收益法 / 市场法**为主，最终以评估机构报告为准。

### 5.4 共益债与必要支出识别

预重整及后续重整期间，下列支出原则上按共益债务或必要费用安排：

1. 保交楼续建工程款、材料款、监理费；
2. 必要的物业维护、安保、临水临电费用；
3. 审计评估、法律、财务顾问等中介费用；
4. 经批准的共益融资利息及费用；
5. 为继续营业应付的必要经营费用。

## 六、保交楼与在建项目处置安排

### 6.0 总体原则

坚持“**一项目一策、保交楼优先、资金封闭运行、交付与化债协同**”。

### 6.1 项目分类

| 类型 | 判定标准 | 处置思路 |
| --- | --- | --- |
| A类：具备续建交付条件 | 去化较好、续建资金可闭环、购房人集中 | 优先续建、专项借款/共益融资、封闭管理 |
| B类：需盘活后方可交付 | 存在资金缺口但资产有价值 | 引入代建/收并购、转让项目公司股权、配建资源 |
| C类：无续建价值或严重资不抵债 | 市场差、成本倒挂、纠纷复杂 | 依法终止、资产变现、按清偿顺序分配 |
| D类：持有型物业 | 商业、办公、酒店等 | 经营改善、整售、REITs路径或抵债 |

### 6.2 保交楼资金来源

1. 项目自身销售回款（预售资金监管账户内资金优先用于续建）；
2. 保交楼专项借款 / 专项基金；
3. 共益债务融资；
4. 战略投资人新增资金；
5. 非核心资产变现后按规定注入；
6. 施工方、材料商以“工程抵房 / 以物抵债”等方式降低现金支出。

### 6.3 项目公司资金封闭管理

对纳入保交楼的重点项目实行：

1. 设立或完善预售资金监管与续建资金专户；
2. 制定《项目续建资金使用计划》并按月披露；
3. 销售回款优先支付续建必要支出，再按约定顺序清偿；
4. 禁止挪用项目资金至集团其他用途。

### 6.4 交付安排与购房人保护

1. 明确各项目计划复工时间、节点工期与交付批次；
2. 对已网签、已付款购房人，原则上继续履行交付义务；
3. 对确无法交付的，依法协商退房、换房或以同类权益安置；
4. 质量、面积差异、延期违约金等，在重整框架下依法协商或按裁定处理。

## 七、债务重组方案

### 7.1 总体思路

结合当前“现房存货约 8,000 万（可办证、无抵押）、应收约 2,500 万、已知负债约 8,320 万（工程款 5,800 / 配套费 1,900 / 供应商 500 / 退房款 120）、现金不足”的结构，采取：

**“打通办证 + 工程款以房抵债为主 + 应收与急售回笼现金清小债”**

的综合路径；优先庭外分类和解，谈不成再转预重整。

**目标结构（6—12 个月内，供谈判）：**

| 债务类别 | 金额（万元） | 主要方式 |
| --- | --- | --- |
| 退房款 | 120 | 全额现金，30 日内优先清零 |
| 城建配套费（住建局） | 1,900 | 争取随过户逐套缴或首付+分期，用于解锁办证 |
| 工程款（单一总包） | 5,800 | 一揽子和解：以房抵债 4,500—5,200 + 现金头款 300—500 + 留债 300—800 |
| 供应商 | 500 | 小额折扣现金 + 部分车位/小户型抵债 |
| 现金来源 | — | 应收回收 1,500—2,000 + 急售变现约 2,500—3,500 货值 |

### 7.2 有财产担保债权

1. 担保财产与续建交付密切相关的，担保权人同意暂缓处置，支持续建；
2. 项目交付或资产变现后，在担保财产价值范围内优先受偿；
3. 不足部分转入普通债权，按普通债权方案清偿；
4. 可协商调整利率、宽限期、还款计划，或置换为更优担保结构。

**可选路径示例：**

- 展期【3—8】年，宽限期【12—24】个月；
- 宽限期利息部分减免 / 挂账；
- 以项目销售回款按比例偿还本金。

### 7.3 建设工程价款优先债权

1. 依法确认是否享有优先受偿权及范围；
2. 对保障续建必要的施工方，优先支付续建工程进度款；
3. 存量工程欠款可通过：现金分期、以房抵工程款、共益债安排、优先受偿财产变现分配等方式清偿；
4. 鼓励施工方复工续建，并就工期、价款、质量责任重新签署补充协议。

### 7.4 购房人相关权利

1. **继续履行交付**：作为优先安排；
2. **不符合交付条件需退款的**：按法律规定和方案安排处理，力争优于普通债权清偿；
3. 已支付房款但未网签、存在登记瑕疵的，依法核查后分类保护。

### 7.5 职工债权与税款债权

1. 职工债权依法优先清偿，预重整期间保障基本工资发放；
2. 税款债权依法申报并按法定顺序清偿，积极争取税务分期与减免政策（如依法可适用）。

### 7.6 普通金融债权

对银行、信托、债券、资管等普通金融债权，综合采用：

1. **期限重组**：展期、分期偿还；
2. **利率调整**：降至【LPR / 约定低利率 / 零息宽限】；
3. **本金阶梯清偿**：按资产变现与经营现金流分段偿还；
4. **债转股**：将部分债权转为重组后企业股权或持股平台份额；
5. **以物抵债**：以房产、车位、商办物业抵偿；
6. **折价清偿**：一次性现金清偿给予折扣（需债权人同意）。

**示例清偿结构（供谈判参考）：**

| 方式 | 比例（示例） | 说明 |
| --- | --- | --- |
| 现金清偿 | 【10%—30%】 | 来源于资产处置、投资人资金 |
| 留债展期 | 【40%—70%】 | 【5—8】年分期，设宽限期 |
| 债转股 / 权益工具 | 【0%—30%】 | 分享未来恢复价值 |
| 以物抵债 | 视项目情况 | 按评估价或协商价抵偿 |

### 7.7 经营性普通债权（供应商、小额债权人）

1. 对单笔金额较小的债权人，可设置**小额债权一次性较高比例现金清偿**，提高效率；
2. 大额供应商可选择：分期现金、以房抵款、转换为共益合作续建；
3. 关联交易形成的债权严格审查，涉嫌无效或可撤销的依法处理，确认部分原则上劣后。

### 7.8 担保与连带债务安排

1. 集团内循环担保、交叉违约条款，在整体方案中统筹解除或重组；
2. 对外担保，根据主债务重组进展同步协商减免、展期或代偿后追偿权处理；
3. 保证人、抵押人与债务人一并纳入谈判的，推动“一揽子”解决。

### 7.9 共益融资安排

为保障续建与必要运营，可引入共益融资：

1. 融资用途限定于保交楼、必要经营及程序费用；
2. 清偿顺序依法优先于普通债权；
3. 可提供项目资产抵押、应收账款质押、账户监管等增信；
4. 须向主要债权人披露并争取认可，转入正式重整后依法确认。

## 八、经营重整与治理安排

### 8.1 经营重整措施

1. **收缩战线**：退出非主业、非核心区域与低效项目；
2. **聚焦交付**：集中资源完成A类、B类项目复工交付；
3. **降本增效**：精简管理层级、控制费用、优化营销；
4. **销售去化**：合理定价、渠道联动、工抵房合规转化；
5. **资产盘活**：商办物业招商运营、整售或轻资产输出；
6. **合规经营**：完善预售资金监管、工程结算、信息披露。

### 8.2 治理结构调整

1. 重组完成后重建董事会、监事会（或监事）及管理层；
2. 战略投资人可提名董事并参与重大事项决策；
3. 建立债权人观察 / 监督机制（过渡期内）；
4. 完善关联交易、资金调度、对外担保内控制度；
5. 对原管理层功过评估，依法追责侵占、挪用、欺诈性转移等行为。

### 8.3 业务存续模式选择

可选模式（择一或组合）：

1. **存续式重整**：保留开发主业，轻装上阵；
2. **出售式重整**：核心项目/股权转让给投资人，原主体清理债务；
3. **清算式重整辅助安排**：无价值板块清算注销，有价值板块重整；
4. **代建+股权合作**：由具备交付能力的房企或建企接盘代建。

## 九、出资人权益调整方案

### 9.1 调整原则

根据资产负债状况，出资人权益应大幅调整，以换取债务减免、期限重组及新投资进入。

### 9.2 调整方式（示例）

1. 原股东持股比例降至【X%】或清零；
2. 资本公积金 / 未分配利润弥补亏损；
3. 定向增发引入战略投资人，形成新的股权结构；
4. 转增或发行股权用于债转股；
5. 原股东以现金、优质资产或解除担保义务作为保留少量股权的对价。

### 9.3 重组后股权结构（示意）

| 股东类别 | 重组后持股比例（示例） | 说明 |
| --- | --- | --- |
| 战略投资人 | 【51%—80%】 | 控股并负责后续经营 |
| 债转股债权人平台 | 【10%—30%】 | 金融债权人持股 |
| 原股东 / 管理层 | 【0%—10%】 | 视贡献与追责情况 |
| 员工激励平台 | 【0%—5%】 | 可选 |

最终比例以投资协议及债权人会议表决结果为准。

## 十、引入战略投资人安排

### 10.1 投资人标准

1. 具备房地产项目操盘、交付与资金实力；
2. 无重大违法失信记录；
3. 认可保交楼与依法重整目标；
4. 能够提供明确的资金安排与交付时间表；
5. 优先考虑：央企/国企房企、地方国资平台、AMC、产业资本联合体。

### 10.2 投资方式

1. 收购增资扩股；
2. 收购收购项目公司股权；
3. 提供共益融资 + 附认购权；
4. 资产包收购；
5. “股权 + 债权 + 代建”组合交易。

### 10.3 投资人权利与义务

**权利：** 依约取得股权/资产、参与治理、获取重组收益。  
**义务：** 按约定注入资金、保障续建交付、承接必要人员与合同、履行信息披露。

### 10.4 遴选程序

公开招募或定向谈判 → 尽调报价 → 专班与债委会评审 → 签署投资框架协议 → 作为重整投资人写入正式重整计划。

---

## 十一、职工权益保障

1. 预重整期间依法支付职工劳动报酬、缴纳社保公积金（按方案资金计划执行）；
2. 不裁员或依法稳妥分流，优先通过岗位调整安置；
3. 经济补偿、工伤等按法律规定处理；
4. 核心工程、交付、财务、法务岗位人员保持稳定；
5. 职工债权如有拖欠，依法优先安排清偿。

---

## 十二、预重整与正式重整的衔接

### 12.1 转入正式重整的条件

具备下列条件时，及时申请转入正式重整：

1. 资产负债与债权结构基本核查清楚；
2. 主要债权人已就重组框架达成书面意向或预重整协议；
3. 保交楼续建路径与资金来源基本明确；
4. 战略投资人有实质性进展（框架协议或保证金到位）；
5. 职工、购房人等群体风险总体可控。

### 12.2 预重整成果的效力衔接

1. 预重整期间形成的债权确认、评估、审计成果，经法定程序可在正式重整中承继使用；
2. 预重整协议中关于债务减免、清偿方式、出资人调整、投资人权利义务等安排，在重整计划中吸收并依法表决；
3. 已支付的共益性费用、续建资金，依法申请确认为共益债务或取回/优先安排；
4. 人民法院认为符合条件的，可依实践对预重整程序效力予以认可（以当地司法实践为准）。

### 12.3 重整计划执行期

建议正式重整计划执行期为【3—5】年，设监督期，由管理人或法院指定监督人监督实施。

## 十三、风险揭示与应对措施

| 风险类型 | 具体表现 | 应对措施 |
| --- | --- | --- |
| 续建资金不到位 | 停工延长、交付延误 | 落实专项借款、共益融资、投资人资金；封闭管理 |
| 债权人协商不成 | 无法形成多数决基础 | 分类谈判、小额高比例现金、府院协调 |
| 销售去化不及预期 | 回款不足 | 定价策略、工抵转化、整售商办 |
| 诉讼执行冲击 | 核心资产被查封处置 | 协调中止执行、提供替代担保、加速转重整 |
| 投资人退出 | 方案落空 | 设置备选投资人、分阶段付款与违约责任 |
| 维稳与舆情 | 购房人/职工集访 | 专班接待、信息公开、交付承诺可核验 |
| 法律效力不确定性 | 预重整安排未被认可 | 关键条款写入正式重整计划并依法表决 |
| 道德风险与资产转移 | 贬损责任财产 | 审计追责、撤销权/无效行为主张、控制权交接 |

## 十四、方案生效与实施保障

### 14.1 预重整阶段的生效

本方案在预重整阶段作为协商基础文本，经下列程序后作为下一步工作依据：

1. 债务人内部有权机构审议通过；
2. 临时管理人审核同意；
3. 府院联动专班意见征询；
4. 债权人协商委员会 / 主要债权人书面认可或签署《预重整协议》。

### 14.2 正式效力

涉及债务减免、出资人权益调整、担保变更等事项，最终以：

**债权人会议表决通过 + 人民法院裁定批准的重整计划**  

为生效依据并全面实施。

### 14.3 实施保障

1. 明确实施主体、时间表与里程碑；
2. 建立资金监管、工程进度、交付节点考核；
3. 违约救济：投资人违约没收取金/保证金，债权人反悔按协议违约条款处理；
4. 重大事项报告与变更机制；
5. 完成后申请重整计划执行完毕裁定，依法办理解除限制消费、信用修复等事宜。
