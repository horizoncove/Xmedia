# 大学城街区业态对标（给招商用的短版）

完整扫描：`docs/招商知识库/原文/对标研究/大学城周边商业街区业态扫描.md`  
编制：2026-08-30。公开资料，不是铺位普查。

## 先记住

大学城周边商业有 **六种原型**。抄错原型，街会死。

| 原型 | 是什么 | 沣西 |
| --- | --- | --- |
| A 校门烟火街 | 下课能走到的吃喝修印 | **一期的脸** |
| B 校园 Mall | 连锁+影院+超商 | **吾悦已占** |
| C 城市级商圈 | 五角场 / 光谷步行街 | 体量差一级，不对标客流 |
| D 内容文化街 | 大学路 / 弘大 / 哈佛旧貌 | 只偷 C 带，不抄整街 |
| E 住配套混合 | OSU Gateway、二期该做的 | **二期的脸** |
| F 校园内市场 | 新加坡 UTown | 2027 还不是威胁 |

## 全国最有用的三句话

1. **广州大学城：** 地铁旁综合商业因离宿舍远被拆；学生日常在贝岗/南亭村街，周末逛 GOGO。规划打不过步行距离。
2. **五道口：** 成府路餐饮曾约 80%，后来要清退「低端餐」、补社区和白领——纯学生餐养不活升级后的租金。
3. **长安万科 / 熙街后期：** 都在往亲子、医疗、酒店、运动补，承认青春餐酒不是终点。沣西吾悦已经把 B 做了，街不必再做一遍。

## 全球最有用的三句话

1. **暑假掉约 25% 客流**（ICSC 对美国校园零售）。没有居民/医院/办公，街融不到资。奥斯汀 The Drag 被称为全市最难零售带。
2. **买在大城市，局在校门。** 早稻田通只做平价餐、居酒屋、旧书；大买去新宿。和「吾悦负责买，这里负责局」同构。
3. **夜市顶住宅会被赶走**（台北师大）。夜场必须锁在已规划广场，二期公寓底商做服务。

## 学生真正高频的菜单（全球几乎同一张）

茶咖 · 能翻台的午饭 · 夜宵 · 便利/打印/美护 · 成局的玩（唱/电竞/剧本杀/球）· 能站人的夜摊。  
**不是** 优衣库、影院、孩子王、珠宝。

## 对一期 / 二期

- 一期五带（S/P/W/C/H）已经是全球 A 类的正确写法。看完对标 **不要加影院和优衣库**。
- 二期继续：**一期卖局，二期卖住和产能。** 茶饮烧烤剧本杀默认不新开。
- 禁止对外使用对标里的宣传口径：「3 公里 40 万」「14 所高校」「光谷年均 1.5 亿」。
