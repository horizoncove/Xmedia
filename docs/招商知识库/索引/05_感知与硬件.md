## 双传感

- **60G 雷达**管人数 / 进出 / 热力
- **CV 只对照**，以后才做身份
- 雷达 **不能认师生**；身份走会员 / 学生证 / 酒店联票

## 首批（只认这些）

室内吸顶雷达 **A1×4** + 室外热力 **A2×2** + 对照相机 **A3×2** + 辅材 B1–B5（PoE / 线材 / 支架 / 边缘网关）。  
**不含车检。** 海康 `DS-TMG035/60G` 是车检/防砸，别买进客流清单。

禁买：24G 照明雷达、人体存在开关、交通测速/道闸防砸雷达。

## 接口合同

中台四字段：`in_count` / `out_count` / `region_count` / `dwell_seconds`（+ heatmap）。  
询价必须要 HTTP / MQTT / SDK，私有化，不绑对方云。

## SLA

桌面通电有进出变化 → 当天 ±15% → POC ≥85% → 开业 ≥95% → 12 个月冲 98%。

安装纪律：**先桌面通电，禁止第一天满场打孔。**

## 硬件二期（可选）

停车人行口、3# 各层通道、4# 大堂、7# MCN 入口、冷区试验点。无平面图不摊面积。

## 和招商的咬合

客流 P0 必须产出：**调铺建议、夜场安保预案、招商画像**。  
热力给调铺，不给收租大屏。90 天后热力偏低，合同允许换品类或换铺。
