# 「二期」口径辨析

材料里「二期」出现过四次，**不是同一件事**。招商对外默认用第 1 种楼盘口径，硬件用第 2 种。不要把西部云谷二期、地铁二期写进 XLOOP 招商 PPT。

## 1. 橙天地楼盘二期（地产分期）

规划总建面约 **18.31 万㎡ = 一期 8.31 万 + 二期 10 万**。  
集中商业约 3 万㎡是街区招商的作业面，不是「二期再建一个商场」。

用户说「Xloop Xmedia 二期」时，最稳妥的读法是：

> **在已冻结的一期开园窗口（→ 2027-05-01）上，把 XLOOP + Xmedia 材料收成可招商的知识体系。**

不是「再开一条新产品线」。

## 2. 感知硬件二期（已决策）

- 车检雷达（含海康 `DS-TMG035/60G`）**移出首批**，二期可选，不算客流主设备。
- 二期点位候选：停车人行口 1 台、3# 各层通道、4# 大堂、7# MCN 入口、冷区试验点。
- **无平面图不许按面积摊台数。** 校准周稳定后再谈数量。

首批只认：室内雷达 4 + 室外热力 2 + 对照相机 2 + 辅材 B1–B5。

## 3. 西部云谷二期（隔壁园区，不是本项目）

- 康定路以南、同文路以西；OSM 约 0.57km。
- 2020-05 投运；公开口径总投资 15 亿、占地 189 亩。
- 「云谷二期更靠近橙天地一侧。」
- 农发行金融科技中心在 **云谷三期**（同文路东，康定路 830 号），不要写成云谷二期。

## 4. 检索噪音（禁止写进招商）

- 创新港「二期转孵化板块」（预重整 run 检索摘录）
- 中心医院二期、地铁 5 号线二期、文创小镇二期学区

## 5. 和「Xmedia 二期」最贴近的业务接口

若把「Xmedia 二期」理解成 **内容产能变现**：

- 7#5F 约 5948㎡ 是可售生产资料（工位 / 直播间 / 代运营）
- 白皮书点名下一份未写的交付：《MCN 招商方案 v1.0》+ 价目表
- 时间锚仍是开业前 9 个月，不是远期二期再招

三类招商不要混成一件事：

1. **铺位招商**（S/P/W/C/H 五带）— 手册 v0.1 已有
2. **MCN 外部招商**（工位/直播间）— 白皮书有价目，无独立手册
3. **合同重构**（数据义务 + 内容协同 + 学生证/工卡）— 谈判清单已有，非法务终稿
