# 1F / 2F 零售清退（短版）

全文：`docs/招商知识库/原文/对标研究/1-2F非餐饮零售清退规则.md`

**1–2 层给吃饭和成局。零售是例外。卖不动又没人进店，五月预警，七月不续。空铺优先补餐，不补第二家衣服店。**

不管餐饮、茶咖、便利、打印、美护。只管理服饰/潮玩/饰品/美妆货架/数码配件等纯零售。

## 配额

1F 纯零售 ≤ **10%** 可租面积；2F ≤ **15%**；两层合计 ≤ **12%**。超了按坪效从低到高清。单店 1F ≤80㎡、2F ≤120㎡。大牌、珠宝、专柜、批发：进场就不批，在的随时清。

## 留铺（比全街更严）

监测仍是九月起、五月警、七月改、一年一签。

- **1F：** 必须挣钱（A），并且进店或成交（B 或 C）达标。只逛不买、或只赚钱但门口没人，都不留 1F。
- **2F：** 营业额或成交达标可留。只进店不买单，六月补成交，补不回七月清。
- 1F 零售不签 1+1+1，最多续一年；连续两年纯零售，第三年默认不再给 1F。

达标线：1F 用同层零售中位 80%；2F 用 70%。B 是 **进店**，不是门口路过。
