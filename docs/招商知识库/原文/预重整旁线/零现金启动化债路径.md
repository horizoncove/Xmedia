# 零现金、变现困难情形下的启动路径

**最新约束（已确认）：**

| 条件 | 状态 |
| --- | --- |
| 账面现金 | **完全没有** |
| 存货变现 | **困难**（去化慢、难以及时换成现金） |
| 存货形态 | 现房，可办证，无银行抵押 |
| 应收 | 约 2,500 万（按揭/尾款，亦非即时现金） |
| 工程款 | 5,800 万，单一总包 |
| 城建配套费 | 1,900 万，交住建局 |
| 供应商 | 500 万 |
| 退房款 | 120 万 |

> 原方案中“先筹现金再缴费、再给总包头款”的路径，在本约束下**不可用**。必须改为 **零现金启动**。

---

## 一、形势重判

资产还在、负债也可覆盖，但企业已进入：

> **“有房、无钱、卖不动”** 的冻结状态。

此时最大风险不是账面亏损，而是：

1. 总包因拿不到现金而起诉查封，盘面被锁死；  
2. 住建局要求一次性清缴城建配套费，办证通道不开；  
3. 为求变现大幅贱卖，打穿货值后真正资不抵债。

**总原则改为：**

> **能抵的全部抵，能换的尽量换，现金只从“别人的钱”里长出来；绝不倒逼自己先掏现金。**

---

## 二、零现金总策略（一句话）

```text
住建局：只谈“随过户逐套缴”，不谈先缴清
    +
总包：纯以房抵债（或总包代垫单套配套费后拿房）
    +
供应商 / 退房：换房、车位抵、债权展期，不兑现金
    +
种子现金：只从应收清收、带配建过户的成交里长出来
```

---

## 三、四类债务的零现金改法

### 3.1 城建配套费 1,900 万（住建局）——只能走“不垫资”模型

零现金下，**淘汰**“先缴 600—900 万开通办证”。

只保留两条：

| 方案 | 内容 | 为何可行 |
| --- | --- | --- |
| **A. 随过户逐套缴纳（唯一主路径）** | 哪套要办证/过户，就先缴该套应摊配套费 | 不要求公司先拿出整笔 1,900 万 |
| **B. 受让方 / 总包代垫** | 总包或买受人先垫该套配套费，开发商在房价/抵债价中扣减 | 用对方的钱打通单套办证 |

向住建局报送时的表述应改为：

> 公司现无货币资金，一次性清缴将导致项目彻底停摆；请求批准按套随登记缴纳城建配套费，实现“办一套、缴一套、活一套”。

若窗口坚持一次性缴清 → **立即升级政府化解专班**，这是零现金情形下的生死线，不能耗在窗口扯皮。

### 3.2 工程款 5,800 万（单一总包）——改为“纯房抵 + 代垫配套费”

取消原“现金头款 300—500 万”。新报价：

| 方式 | 金额（万元） | 说明 |
| --- | --- | --- |
| 以房抵债 | 5,200—5,800 | 尽量一次抵满或接近抵满 |
| 总包代垫配套费 | 按拟过户套数应摊 | 代垫后在抵债房价中扣减，或另行计为对开发商债权后继续抵房 |
| 现金头款 | **0** | 明确告知无现金；如需现金，只能等后续第三方销售后分成 |
| 或有短分期 | 0—400 | 仅当总包坚持留一点现金债时，挂在共管账户，有回款再付 |

**给总包的可接受交换条件（用权利换现金让步）：**

1. **优先选房权**：先让总包挑去化相对好的现房；  
2. **抵债单价更优惠**：可谈到市场价 **80%—90%**（用折扣换零现金）；  
3. **过户批次优先**：配套费路径一通，第一批先过总包的房；  
4. **协助其对外处置**：开发商配合总包再销售、包销、分销；  
5. **结算一次性定案**：减少扯皮，让总包内部好决策。

**必须坚持的条款不变：**  
停诉停执、分包与农民工由总包内部消化、不得再拍卖同一债权。

### 3.3 退房款 120 万——零现金下不硬兑

| 可选方式 | 适用 |
| --- | --- |
| **换房安置**（首选） | 以等价或略优现房换签约，消灭退房现金债 |
| 延期退房 + 书面分期 | 客户坚持退款但可谈时 |
| 转债权确认 + 优先受偿小额安排 | 进入预重整时再用 |
| 首笔应收到位后再清 | 仅对最敏感个案 |

原则：零现金阶段 **不承诺短期内全额现金退房**，避免开先例。

### 3.4 供应商 500 万——全面抵房 / 抵车位

| 方式 | 安排 |
| --- | --- |
| 车位 / 储藏室 / 小户型抵债 | 主路径 |
| 分期挂账 12—24 个月 | 不愿拿房的供应商 |
| 现金折扣清偿 | **暂停**，除非出现种子现金 |

## 四、种子现金从哪里长出来（不靠“先有钱”）

零现金不是永远无现金，而是 **启动时无现金**。种子现金只允许从下列来源长：

### 来源 1：应收账款 2,500 万（最真实）

这是当前唯一不依赖新买家的潜在现金。

动作升级为“救命级”：

1. 列出已批未放按揭，按户死磕银行放款；  
2. 对有能力客户给 **结清折扣**（用账折换现金）；  
3. 确无回收可能的，尽快解约转存货，并入抵债/再售池。

> 哪怕先只收回 200—300 万，也能启动首批“单套配套费 + 极敏感退房”。

### 来源 2：带配建过户的成交（卖一套、缴一套、剩一点）

流程改成：

```text
客户签约并支付房款
  → 房款进共管账户
  → 先扣该套城建配套费交给住建局
  → 余款再分配（总包分期 / 敏感退房 / 必要费用）
  → 过户
```

定价上可接受比原货值更深折扣（如下浮 **10%—20%**），但必须是 **真回款、真过户**，不能为去化而去化到整体打穿。

### 来源 3：总包 / 接盘方“房+代垫配套费”包

对总包或本地国资/包销商谈：

> 你选走一批现房；每套过户所需城建配套费由你先垫；价款在抵债总额或包销价里扣。

这等于用资产换别人代付行政收费，是零现金下打通办证的常用结构。

### 来源 4：政府协调下的专项支持（视当地政策）

如纾困基金、国资收储存量、配套费缓缴批复等。零现金情形下应主动写报告进专班，不要只在企业与总包之间空转。

## 五、重排后的动作顺序（按天）

### 第 1—7 天：冻结冲突 + 打开两扇门

1. 书面告知总包：无现金，但可立即启动现房一揽子抵债；请停诉停执；  
2. 向住建局提交《随过户逐套缴纳城建配套费申请》，抄送政府化解专班；  
3. 应收台账按户分工，每天盯按揭放款；  
4. 退房客户改为换房谈判，停止现金承诺。

### 第 8—21 天：签两份关键文件

1. 与总包签《纯以房抵债一揽子和解协议》（现金头款为 0 或有回款再付）；  
2. 取得住建局 / 专班关于随过户缴纳的书面意见或会议纪要；  
3. 选定首批过户房源（优先总包抵债房 + 已成交待办证房）。

### 第 22—60 天：办证滚动起来

1. 总包代垫或共管账户按套缴配套费 → 首批过户；  
2. 应收每到一笔，只用于：单套配套费、极敏感维稳、必要过户费用；  
3. 供应商推车位/小户型抵债；  
4. 若总包拒签且起诉查封 → 立即转预重整。

## 六、与原方案的对照（避免执行混乱）

| 事项 | 原方案（有现金预期） | **零现金方案（现行）** |
| --- | --- | --- |
| 总包头款 | 300—500 万现金 | **0**；用选房权 + 价格折扣换 |
| 配套费 | 可先缴 600—900 万 | **禁止垫大额**；只做随过户 / 对方代垫 |
| 退房款 | 优先全额现金 | **换房为主**，现金只等种子回款 |
| 供应商 | 部分折扣现金 | **全面抵房/挂账** |
| 急售折扣 | 5%—10% | 真回款前提下可到 **10%—20%**，但须进共管 |
| 程序 | 偏庭外 | 庭外仍优先；**21 天谈不成总包或住建局，就准备预重整** |

## 七、何时必须转预重整

零现金下，预重整触发线更靠前。出现任一情形即转：

1. 总包拒绝纯房抵，坚持大额现金并已查封核心房源；  
2. 住建局书面拒绝随过户缴纳，又无专班协调结果；  
3. 多起供应商/退房诉讼导致无法过户；  
4. 应收 60 日内几乎回收为 0，且无一笔真销售闭环。

预重整的作用：把“随过户缴费、以房抵债、停执”装进有司法/府院背书的框架，避免被单一执行打穿。

---

## 八、给决策层的一句话

> 现在不是“筹钱还债”阶段，而是“用现房换停火、用政策换办证、用应收造种子现金”阶段；谁先逼你掏现金，谁就在把盘面推向拍卖。
