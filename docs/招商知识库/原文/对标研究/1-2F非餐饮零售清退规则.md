# 1F / 2F 非餐饮（零售）清退规则

| 项 | 值 |
| --- | --- |
| 版本 | v0.1（经营制度，非法务终稿） |
| 日期 | 2026-08-30 |
| 管谁 | **1F、2F 的非餐饮铺，主要是零售** |
| 不管谁 | 餐饮、茶咖、夜宵；便利 / 打印 / 美护 / 药店等生活服务；3F 及以上；7#5F MCN |
| 和学年总规则的关系 | 总规则（一年一签、九月监测、五月预警、七月调改）仍然有效。本规则是 **1–2F 零售的加严条款**：冲突时听本页 |

一句话：

> **1–2 层是街的脸，给吃饭和成局。零售想站在这里，必须能卖钱，或者真能把人拉进店。卖不动又没人进，五月预警，七月到期不续。空出来优先补餐、补局、补服务，不补第二家衣服店。**

白皮书里 4#1F、7#1–2F 本来就是餐饮。零售是挤进来的例外，不是默认业态。

## 0. 哪些店算「零售」，必须走本规则

签约时打标签。标签是零售，就走本页，不能事后改口成「生活集合」。

| 算零售（本规则） | 不算（走学年总规则） |
| --- | --- |
| 服饰、鞋包、运动装 | 正餐 / 简餐 / 面 / 快餐 |
| 饰品、廉价潮玩、盲盒、文创货架 | 茶饮 / 咖啡 |
| 美妆集合、开架彩妆、香水 | 烧烤 / 夜宵摊 |
| 数码配件、耳机壳、低端 3C | 便利店 / 小超 |
| 眼镜（非医疗处方为主）、文具精品 | 打印 / 证件照 |
| 礼品、伴手礼、鲜花零售（无服务台） | 理发 / 美甲 |
| 珠宝、黄金、腕表（本就禁入，见下） | 药店 / 诊所 |
| 书店里的货架零售（无座位、无活动） | 剧本杀 / 密室 / 电竞 / 台球 |

灰区：名创优品、KKV、好特卖一类「杂货零售」= **零售**。鲜花+现场包装、眼镜+验光 = 服务，走总规则。

## 1. 1–2F 零售先过「还能不能进」

### 1.1 进场红线（不批，已在的随时清）

和手册禁入对齐，1–2F 零售额外写死：

- 大牌服饰、奥莱同款、优衣库级（吾悦已有）
- 珠宝、黄金、腕表、化妆品专柜
- 服装批发、货架仓库式零售
- 孩子王、母婴集合
- 单店面积 **1F > 80㎡ 或 2F > 120㎡** 的纯零售（占掉午饭和夜场面）
- 1F 沿街连续 **两家以上** 同质服饰/饰品

这些 **一票否决**，不等九月监测、不等七月。

### 1.2 进场配额（没有铺位表前先锁比例）

铺位 Excel 未到，先按 **1–2F 可租面积** 卡：

| 层 | 纯零售上限 | 原因 |
| --- | ---: | --- |
| **1F** | **≤ 10%** | 一层是南门和白领午饭的脸 |
| **2F** | **≤ 15%** | 略宽，仍不能做成服装层 |
| 1F+2F 合计 | **≤ 12%** | 超了先清零售，不清餐饮 |

超配额时：即使某家 A/B 勉强过线，七月也按 **坪效从低到高** 清到回到配额。配额优先于单店求情。

允许留下的零售类型（仍要过第 2 节指标）：廉价潮玩/饰品、学生文创、小数码配件。各 **1–2 家**，客单 <50。不是开一条零售街。

## 2. 留 / 清：1F 比 2F 更严

学年总规则是「挣钱或带人，中一条就留」。  
**1–2F 零售不配享受这么松。** 占的是最好的层。

监测仍从 **八月底九月初** 起，五月预警，七月不续。合同仍一年，到期卡 7 月 31 日。首批签到 2028-07-31。2027-05–08 试跑，不计分。

### 2.1 测什么（零售专用三列）

| 列 | 测 | 1F 零售达标 | 2F 零售达标 |
| --- | --- | ---: | ---: |
| **A 挣钱** | 学年营业额；有面积则看 **坪效（元/㎡·月）** | ≥ 同层 **零售** 中位 **80%**，且不得低于同层餐饮中位的 **40%**（防「小店混中位」） | ≥ 同层零售中位 **70%** |
| **B 进店** | 进门客流（雷达进店，不是门口路过） | ≥ 同层零售中位 **80%** | ≥ 同层零售中位 **70%** |
| **C 成交** | 学年成交笔数（收银/抽成/核销） | ≥ 同层零售中位 **70%** | ≥ 同层零售中位 **60%** |

利润能核作加分。核不清，用营业额和坪效。  
门口站人但不进店，**不算 B**。零售的 B 是进店，不是店前热力。

同层零售不足 3 家、中位不稳时：用「该层全部非餐铺」当参照，并在月报里写明。

### 2.2 判定

**1F 零售（沿街 / 广场一圈）：**

| 条件 | 七月 |
| --- | --- |
| A 达标，且（B 或 C）达标 | **留，可续一年**（只续一年，不谈 1+1+1） |
| 只 A 好，B、C 都差 | **不留 1F**。可申请降到 2F 或改成服务/餐；不改则不续 |
| 只 B 好（进店多）但 A、C 都差 | **不留 1F**。逛不买，挡的是能开饭的铺。五月预警，七月清 |
| A、B、C 都差 | **必清** |

1F 零售 **不能** 只靠「人多不买」留铺。总规则里「引流店可留」指的是蜜雪、出片茶，不是衣服店。

**2F 零售：**

| 条件 | 七月 |
| --- | --- |
| A 或 C 达标 | **留，可续一年** |
| A、C 差，但 B 达标 | 黄灯：六月必须做出成交（C 拉到 60%）。拉不回来，七月不续 |
| A、B、C 都差 | **必清** |

### 2.3 一票否决（随时清，不等七月）

除总规则那几条外，1–2F 零售加：

- 连续 **30 天** 无成交记录（报零或拒报）
- 把铺当仓库 / 直播囤货、不对外营业
- 1F 营业时段不覆盖 **11:30–13:30 或 17:00–21:00**（空铺脸）
- 拒报营业额、拒接收银/抽成接口超过 **2 个月**
- 货盘改成禁入品类

## 3. 合同怎么签（零售专用）

| 条 | 口径 |
| --- | --- |
| 租期 | 12 个月，到期 7 月 31 日。首批到 2028-07-31 |
| 续签 | 1F 零售达标只续 **1 年**，不签 1+1+1。连续两年都是纯零售且不升服务/餐，第三年 **默认不再给 1F** |
| 2F 零售 | 达标可 1+1；第三年仍要过指标 |
| 标签 | 合同写「业态：零售」，不得自行改成餐饮；改业态须重批，且不得变成禁入 |
| 收银 | 1–2F 零售 **必须** 接指定收银或抽成。这是进场条件，不是倡议 |
| 腾铺 | 不续后 **7 天**；空铺 **48 小时** 内快闪或新店围挡 |
| 补位方向 | 空出的 1F **先补餐 / 茶咖 / 便利 / 能午饭的店**；2F 先补餐或局。零售候补排最后，且不得突破第 1.2 节配额 |

对零售商户原话：

> 一层二层是吃饭和开局的地方。你卖货可以，但要卖得动或人真进店买单。只挂衣服、靠路过，五月通知你，七月到期请让铺。铺会给能开饭、能成局的店。

## 4. 日历（和学年总规则同一套，零售多两步）

| 时点 | 全街 | 1–2F 零售加做 |
| --- | --- | --- |
| 签约 | 一年一签 | 打「零售」标签，签收银接口，确认层配额还没超 |
| 2027-05–08 | 试跑 | 清点 1–2F 零售家数和面积，超配额的标红（当年不强制清） |
| 每年 8 底 / 9 初 | 监测开始 | 零售出 A/B/C 三列，月报给商户 |
| 次年 5 月 | 预警 | 1F：缺 A 或（B、C 都缺）就预警。2F：A、C 都缺就预警 |
| 6 月 | 整改 | 1F 只接受「补成交」或「书面申请改餐/改服务/降楼层」 |
| **次年 7 月** | 调改 | 不续、腾铺、按补位顺序进店；配额清到红线内 |
| 8 月 | 迎新 | 1F 新零售原则上 **不再新开**，除非配额有空且过进场红线 |

## 5. 清完补什么（1–2F 空铺）

按序，高优先先补：

1. 能午饭的简餐 / 面 / 西北快餐（工卡套）
2. 茶饮 / 平价咖啡
3. 便利（1F 若还没有 24h）
4. 打印照相、学生美护（服务，不是零售）
5. 局的窗口或预约台（剧本/密室的临街接待，主体仍在成簇区）
6. **最后才是零售**，且仍受 10% / 15% 配额

禁止：用另一家服饰顶掉被清的服饰。

## 6. 给法务的句子（可直接贴进零售铺合同）

1. 本铺业态为零售，位于 1 层或 2 层；适用《1F/2F 非餐饮零售清退规则》。
2. 承租人须接入指定收银或抽成系统，按月提供营业额与成交笔数。
3. 1 层零售须同时满足：学年坪效达标，且进店客流或成交笔数达标；否则期满不再续租。
4. 2 层零售须学年营业额或成交笔数达标；仅进店无人买单的，预警后仍不达标则不续租。
5. 1 层纯零售不提供超过 12 个月的续租承诺，亦不适用 1+1+1。
6. 期满不续的，7 日内腾铺；出租人有权立即安排餐饮、服务或快闪，承租人不得阻碍。
7. 出租人有权将 1–2 层零售总面积控制在公示配额内；超配额时按坪效从低到高终止到期租约。

租金数字仍不写死。

## 7. 和总规则怎么同时用

| 店 | 听谁 |
| --- | --- |
| 1–2F 餐饮 / 茶咖 | 学年总规则（A 或 B） |
| 1–2F 便利 / 打印 / 美护 | 学年总规则 |
| **1–2F 零售** | **本规则（更严）** |
| 3F 及以上零售 | 学年总规则；仍禁大牌珠宝专柜 |
| 一票否决 | 两套都执行，就高不就低 |

董事会看三件事：1F 零售面积有没有压在 10% 内；七月清掉的是不是「卖不动也不进店」；空铺 48 小时有没有补成餐或服务。
