## 1. 桌上只有两套东西，不是三套楼账

**套 A · 当场资金口径（决策人，本周）**

```
一年：3# 收租 779  +  自营三店 273  −  1F 返租 505.9  =  546
一次：卖掉 1F，回笼 5270
```

当场还说死了两件事：

- 3# **纯租赁**
- 7# **自营**：宝藏星球 + 体育奥莱 + LBD，利润按 273

这五个数自己能对上，没有缺口：

| 反推 | 数 | 严不严 |
| --- | ---: | --- |
| 779 ÷ 6,683㎡ ÷ 12 | **≈97 元/㎡·月** | 严。779 就是 3# 满租，不是 7#、也不是 1F 转租 |
| 505.9 ÷ 160 ÷ 12 | **≈2,635㎡** | 严。返租面积是「卖掉的 1F」，没写是哪一栋 |
| 5,270 ÷ 2,635 | **≈2.0 万/㎡** | 严。卖铺单价 |
| 160 × 12 ÷ 20,000 | **9.6%/年** | 严。给小业主的现金回报 |
| 273 | 三店利润 | **只有这个口，没有面积、没有楼层** |

**套 B · 白皮书产品口径（2026-08-10）**

- 7# 整栋 7,538㎡、5 层
- 文字：1–2F 餐饮，3–4F KTV/电竞，5F MCN
- 又写：7#5F 约 5,948㎡、「四层直播」
- MCN 工位/间年化 500–1000 万（规划，不是当场账）

5,948 和「5F 一层」和「整栋 7,538」在白皮书里就没对齐。这是规划稿笔误，不是第三本财务。平面图没到之前，5,948 只当「MCN 规划面积」，不从 7,538 里硬扣，也不当 5F 单层。

**招商手册、1–2F 清退、寒暑假规则，跟的是套 B。**  
**546 万那张表，跟的是套 A。**  
两套都还在用。这就是「怎么回事」。

## 2. 546 万算的是什么（也只算这个）

```
卖一层（2,635㎡）换 5,270 万现金
每年固定付给买铺的人 505.9 万，把经营权买回来
用 3# 整栋出租把 505.9 盖住，还剩 273
再加上三家自营店的 273，账面 546
```

4# 酒店不在这张表。7# 楼上不在这张表。MCN 500–1000 不在这张表。  
不是忘了加，是这张表从头就不是「三栋楼 P&L」。它是 **卖铺 + 兑付 + 教育楼租金 + 三店利润**。

三店 273 盖不住返租 506（覆盖率 54%）。缺口 233 万，由 3# 的租补。自营归零时，3# 得出让 **65%**，否则兑付穿。这一条仍然成立。

## 3. 7# 在这两套里各是什么

| | 套 A（钱） | 套 B（街） |
| --- | --- | --- |
| 7# 是什么 | 三家自营零售的名字 | 夜场 + MCN 的楼 |
| 进 546 的钱 | 只有 273 | 0 |
| 1–2F | 奥莱 / 潮玩 / LBD | 餐饮 |
| 3–5F | **没说** | KTV / 电竞 / MCN |
| 和 1F 散售的关系 | 没指定 2,635㎡ 在哪栋 | 白皮书写 7#1–2F 是餐，没写卖 |

所以：**不是「没把 7# 的 877 万算进去」。**  
7# 在套 A 里就被定义成自营三店，不是待租的教育楼。用 3# 的 97 去乘 7,538，得到 877、再说「少看 604 万」——那是把套 B 的空楼，按套 A 的 3# 单价去租。决策人已经说了 7# 不按 3# 那条路走。

上一版还把 7#1F 默认塞进 2,635㎡，算出「本栋返租 289、当场贡献 −16」。面积分配没有出处。2,635 是卖掉的 1F 合计：3# 不卖，剩下只可能是 4#1F、7#1F、以及未点名的沿街 1F，**比例未知**。

最说得通、但仍是推断的物理图像（标成推断）：

> 卖掉的 2,635㎡ 一层，正是（或大部分是）三店要去经营的铺。卖给小业主，再租回来自己开奥莱。273 是店的利润，505.9 是付给买家的租。7# 作为 7,538㎡ 的楼，只有和「1F / 三店」重叠的那一块进了 546。楼上要么还按套 B 另立项目，要么还没进这本资金账。

推断停在这里。不再拆层板、不再给 7# 摊 289。

## 4. 上次算错的三处（避免再绕回去）

1. **用 97 乘 7# 当主账。** 97 只属于 3#。7# 的当场定义是自营，不是「少收了 604 万房租」。
2. **把 7#1F = 1,508㎡ 写进返租。** 层板是 7,538÷5 的等分，不是测绘；也没有合同说 2,635 里有多少是 7#。
3. **甲 / 乙 / 丙让人挑。** 那是把「两套计划没并账」伪装成三套财务模型。并账之前没有第三套。

还成立、可以留的：

- 779 是 3# 满租
- 273 盖不住 506
- 3# 出租率红线 65%（自营按 0）、操盘线 80%
- 套 A 的 7#（奥莱货盘）和套 B 的 7#（南门夜场）抢同一栋楼；1–2F 清退规则清的正是套 A 这类铺
- 白皮书 5,948 先当规划残留，不当财务面积

## 5. 并账之前，7# 只盯这一句

**套 A 和套 B 谁让路。**

- 7# 按套 A 做满三店：546 那张表不用改；街上的 7# 就不是白皮书那栋楼。招商手册和清退规则要对着改，否则自己清自己。
- 7# 按套 B 做餐 / 局 / MCN：273 不能再当 7# 的数；三店要么撤、要么挪到真的散售 1F（可能在别栋）；MCN 单独立利润中心，进另一张表，不和 546 加总。
- 现在的状态是两套并列。546 继续只描述资金结构。7# 整栋损益在并账之前 **不存在**，不是算漏了。

并账需要的三张纸（缺一仍只能停在上面这句）：散售 1F 的楼栋清单、三店各占几平、7# 分层实测。没有它们，不再反推层板。
