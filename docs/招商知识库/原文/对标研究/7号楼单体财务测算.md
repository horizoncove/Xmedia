## 1. 当场三店：273 万是店账，不是楼账

| 分母 | 273 万折合 | 读法 |
| --- | ---: | --- |
| 整栋 7,538 ㎡ | **30 元/㎡·月** | 前单用过；若三店铺满五层，大学城零售偏乐观 |
| 只占 1–2F 3,015 ㎡ | **76 元/㎡·月** | 更像「货盘在低区」 |
| 只占钥匙 B 的 1,590 ㎡ | **143 元/㎡·月** | 要这个利润，得是高周转潮玩，不是奥莱 |

若 273 是 **利润**、零售净利率按 6% 反推：年 GMV ≈ **4,550 万**。

| 占铺 | 隐含销售坪效 |
| --- | ---: |
| 7,538 ㎡ | **503 元/㎡·月** |
| 3,015 ㎡ | **1,258 元/㎡·月** |

吾悦在侧、学年夜客 4,000–7,000、暑假腰斩。503 已经要旺季；1,258 是城市级奥莱的数，不是南门夜场。LBD 没有面积表，三店先按「低区 3,015、奥莱吃掉一半以上」估，不按铺满 7,538。

**管理账（默认 7#1F 在散售里）：**

```
7# 当场贡献 = 三店利润 273 − 本栋 1F 返租 289 = −16 万
```

三店利润 **盖不住自己一层的兑付**。2–5F 还空着机会成本。前单说「覆盖率 54%」是三店对 **整街** 2,635 ㎡ 返租；落到 7# 头上，覆盖率是 273 / 289 = **94%**，仍差一口，而且没付 2–5F 该收的租。

内部租金不要记 0。占用 7#1F 就记 160；占用 1–2F 自持部分按街铺 80–140。否则奥莱永远「赚钱」。

**和当场 273 比（只比「把楼租出去 vs 三店自营」，MCN 先不混进来）：**

## 4. 压力：7# 自己的红区

公式（万元，默认 7#1F 承担 289 返租）：

`7# 净额 = 低区利润或租金 + 高区租金或 MCN − 289`

| 低区 \\ 高区 | 0（3–5F 空） | MCN 250（腰斩） | MCN 500 | MCN 1000 |
| ---: | ---: | ---: | ---: | ---: |
| 三店亏 150 | **−439** | **−189** | 61 | 561 |
| 三店 0 | **−289** | −39 | 211 | 711 |
| 三店 137（腰斩） | **−152** | 98 | 348 | 848 |
| **三店 273** | **−16** | 234 | 484 | 984 |
| 1–2F 租 434（账乙、无三店） | 145 | 395 | 645 | 1,145 |

读图：

- 高区不贡献时，7# **必亏**（至少亏一层返租）。这是当场账甲。
- MCN 腰斩到 250，三店归零：7# 仍约 −39。MCN 不是彩票，是本栋的地板。
- 低区改回餐饮租 434，即使 MCN=0，7# 也能正（145）。**低区业态比三店利润更决定本栋正负。**

整街红线不变：3# 出租率 65%（自营按 0）。7# 的红线另加一条：**3–5F 连续两个季度收入 < 250 万，且低区利润 < 150 万 → 本栋穿。**

## 5. 操盘含义（只对 7#）

1. **546 万没算 7 号楼整栋。** 算的是三店。3–5F 和 MCN 在表外。决策人若觉得「7# 也在赚钱」，指的应是账乙或账丙，请改口径，不要在 546 上加 500。
2. **自营三店相对整栋出租，每年少看约 450–600 万。** 这是本栋最大的数。要留三店，必须能讲清：留下的货盘值这半栋租金，还是只为了填 1F 空铺。
3. **默认 7#1F 已卖：本栋先亏 289，再谈利润。** 三店 273 刚好咬住兑付，咬不住 2–5F。
4. **白皮书和当场货盘打架。** 1–2F 清退规则写一层给餐和局；奥莱/宝藏星球是要清的那类。7# 脸按白皮书，三店只能当过桥，不能当永动机。
5. **MCN 500–1000 是 7# 该立的利润中心，不是 273 的备注。** 工位/间价目表仍缺。没有它，账丙和账乙的高区都是纸。
6. **预算砍半先砍奥莱面积，不砍 3–5F 内容厂房、不砍 7#1F 兑付。** 和前单一致，现在有楼账撑着。

**给决策人的三步（7# 专用）：**

1. 拍板钥匙 A 还是 B（平面图一到就锁）。同时确认 2,635 ㎡ 里 7# 占多少。
2. 三套楼账选一套进集团表。选甲：承认 7# 净贡献约 −16 到 +273，3–5F 单独立项。选乙：撤三店，1–2F 回餐。选丙：三店缩到 1 个窗口，MCN 价目表本月出。
3. 管理账：7#1F 记内部租金 160；2F 及以上按带定价。周报加两列——7# 低区利润、7# 高区（MCN/娱乐）收入——不要再和 3# 779 搅在一行「自营」。

本单不改招商手册客群口径，不把 15 万师生写进对外稿。铺位表、7# 分层实测、返租合同面积一到，升 v0.2 替换 1,508 / 2,635 / 289。
