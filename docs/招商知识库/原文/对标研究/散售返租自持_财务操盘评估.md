## 0. 先把账还原（假设写明）

当场口径：

| 项 | 数 | 当作什么 |
| --- | ---: | --- |
| 租金 | 779 万/年 | 3# 纯出租的满租收入 |
| 自营 | 273 万/年 | 7# 宝藏星球 + 体育奥莱 + LBD 的 **利润**（压力矩阵也这么用） |
| 返租 | 505.9 万/年 | 1F 散售后付给小业主的刚性租金 |
| 净额 | 546 万/年 | 779 + 273 − 505.9 |
| 散售回款 | 5270 万 | **一次性**卖铺回笼，不是年利润 |
| 返租单价 | 160 | 按 **元/㎡·月** 理解 |

反推（和数字严丝合缝，当作工作假设，不是测绘）：

- 返租面积 ≈ 505.9 万 ÷ (160 × 12) ≈ **2,635 ㎡**
- 散售单价 ≈ 5,270 万 ÷ 2,635 ㎡ ≈ **2.0 万/㎡**
- 给小业主的现金回报 ≈ 160 × 12 ÷ 20,000 = **9.6%/年**
- 3# 若 6,683 ㎡ 满租贡献 779 万 → 隐含租金 ≈ **97 元/㎡·月**

本评估 **未计入**：4# 酒店、7#5F MCN、物业费、能耗、自营存货和人工、返租期满后的回购/市场价重签、税。净额 546 万是「毛经营净额」，不是自由现金流。

## 压力矩阵：自营利润 × 3# 出租率

公式（万元/年）：

`净额 = 779 × 出租率 + 自营利润 − 505.9`

返租是常数。出租率和自营都是变量。红区 = 净额 &lt; 0。

| 3# 出租率 \\ 自营利润 | −150 万（亏） | 0 | 137 万（腰斩） | **273 万（口径）** | 410 万（超预期） |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 40% | **−345** | **−195** | **−58** | 78 | 215 |
| 50% | **−267** | **−117** | 20 | 157 | 294 |
| 60% | **−189** | **−38** | 99 | 235 | 372 |
| **65%** | **−150** | **≈0** | 137 | 273 | 410 |
| 70% | **−111** | 39 | 176 | 313 | 450 |
| 80% | **−33** | 117 | 254 | 390 | 527 |
| 90% | 45 | 195 | 332 | 468 | 605 |
| 100% | 123 | 273 | 410 | **546** | 683 |

读图：

- **自营归零** 时，出租率必须 ≥ **65%**，否则返租把现金吃穿。
- 自营按口径 273 万时，出租率 40% 仍能正（78 万）——这会给人错觉。错觉来自「把自营当稳的」。零售利润不是租金，寒暑假和吾悦一压就会掉。
- 自营亏损 150 万 + 出租率 80%，已经红区边缘（−33）。**奥莱/宝藏星球亏一年，3# 没满租，结构立刻穿。**

红区定义给董事会：连续两个季度净额 &lt; 0，或 3# 出租率 &lt; 65% 且自营 &lt; 0。

## 问 1. 散售 + 返租 + 自持，模式风险

这是中国商业地产最熟悉的「先卖血、再租肺」。一年账能平，不代表模式健康。

**结构**

```
小业主出 5270 万买走 1F
你每年固定付 505.9 万把经营权买回来
3# 自持收租 779 万（弹性）
7# 自营零售 273 万（更弹性）
```

**五条硬风险**

1. **期限错配。** 散售是永久产权（或长产权），返租通常 3–8 年。期满要么继续高息兑付，要么小业主收回铺自己开——1F 业态当场碎。南门夜场最怕一层变成各卖各的。
2. **刚性兑付 vs 弹性收入。** 返租 505.9 万是合同债。3# 空置、7# 零售亏，都不能少给。压力矩阵红区全由这个剪刀差画出来。
3. **9.6% 的承诺太贵。** 大学城商铺市场租金撑不住「给小业主 9.6%」。160 元/㎡·月是 **兑付给买家的价**，不是学生店交得起的价。S 带茶饮、面馆的承受力在手册里是另一档。缺口只能由 3# 租金和自营利润补。
4. **1F 零售自营和街区产品打架。** 宝藏星球 / 体育奥莱 / LBD 是 Mall 货盘，吾悦已经有优衣库、KKV、运动装。1–2F 零售清退规则写的是：一层给吃饭和成局。自营三店占的正是要清的那类铺。
5. **治理权。** 散售后，法务上你是承租人不是业主。返租逾期、协会维权、个别业主不续，统一收银、统一调改、七月清退 **全部卡壳**。一年一签调改制度，对散售铺执行成本最高。

散售 5270 万只能当 **一次回笼**，用来还建安、补现金流。不能折进「年利润 546 万 + 散售」给董事会看——那是把资产负债表的资产出售，加进利润表。

**操盘判断：模式可做，但必须当「过桥」，不能当「永久发动机」。** 返租期内把 1F 从奥莱货盘改成餐/局/服务；期满谈判降到市场租金或定向回购关键铺。

## 问 2. 自营 273 万 vs 返租 505.9 万，结构是否健康

**不健康。** 一句话：自营盖不住返租，3# 在给 1F 小业主发工资。

| | 万/年 |
| --- | ---: |
| 自营利润 | 273 |
| 返租支出 | 505.9 |
| **自营覆盖返租** | **54%** |
| 缺口 | 233 |
| 3# 满租租金 | 779 |
| 3# 租金覆盖返租后剩余 | 273 |
| 再加自营 | 546 |

健康的返租自营，至少自营利润 ≥ 返租 × 1.0，最好 1.2（留存货和淡季）。现在是 **0.54**。

7# 若按 7,538 ㎡ 粗算，273 万利润 ≈ **30 元/㎡·月**。体育奥莱和宝藏星球在大学城夜街，这个数已经偏乐观；寒暑假再腰斩，覆盖率会掉到 0.3 以下。

结构上真正的发动机是 **3# 出租**，不是 7# 自营。自营是「用 233 万缺口买一层货架」，还买了和吾悦正面撞、和南门夜场定位反的货盘。

财务建议：把 7# 自营从「利润中心」改记 **「1F 统一经营权的成本中心」**。考核它的是：有没有把 2,635 ㎡ 按街区五带来用，而不是奥莱毛利。能转租给绿铺、收到接近 160 的更好；收不到就承认 3# 在补贴统一经营权——但补贴要买对的业态。

## 问 3. 出租率底线

分三道线，不要只报一个数。

| 线 | 3# 出租率 | 条件 | 动作 |
| --- | ---: | --- | --- |
| **会计盈亏（自营=273 且稳）** | ≥ **30%** | 自营不垮 | 仅理论值，**不能当操盘线** |
| **安全盈亏（自营=0）** | ≥ **65%** | 零售利润不作数 | **红线**。掉到这以下，返租靠库存现金硬兑 |
| **操盘底线** | ≥ **80%** | 自营按 50% 计提（≈137 万） | 净额约 254 万，才够物业、空置、税的缝 |
| **健康线** | ≥ **90%** | 自营不亏 | 才谈得上 546 万口径接近实现 |

3# 是教育/办公向纯出租。大学城教培受政策和学期影响。手册已禁止再叠中公/粉笔/学而思当街脸；3# 若全是教培，出租率会跟开学绑定，暑假空——正好撞上返租月月要付。

**操盘口令：3# 出租率周报。跌破 80% 黄灯，跌破 65% 红灯（停自营扩张、启动 1F 减品）。**

## 问 4. 租金定价策略

现在桌上有 **两个 160 和 97，不能混。**

| 价 | 是什么 | 不能当成什么 |
| --- | --- | --- |
| **160 元/㎡·月** | 付给 1F 小业主的返租 | 不是学生店、也不是奥莱该交的市场租 |
| **≈97 元/㎡·月** | 3# 满租隐含成交 | 不是 1F 餐饮能照抄的价 |

定价原则：

1. **对小业主：160 是合同，能谈降、不能擅自停。** 预算砍半也不能先砍兑付（见问 6）。
2. **对 3# 承租人：按学年、一年一签，价格跟指标走。** 教育/职训可略高于街铺；空三个月不如降到 80–90 保出租率。保 80% 出租率，比死守 97 更值钱——矩阵里 80%×自营腰斩 仍有 254 万；60%×自营归零是红区。
3. **对 1F 实际使用者（若转租）：按带定价，不按 160。** S 带茶饮/面承受不起 160。能收到 80–120 就收，差的 40–80 元/㎡ 记「统一经营权补贴」，由 3# 出。硬按 160 招零售/奥莱，招来的就是要在七月清的店。
4. **自营三店：不要用内部「零租金」假装赚钱。** 管理账要记 160 × 占用面积，才能看见奥莱是不是在烧返租。
5. **抽成：1–2F 必须接。** 散售铺尤其要接，否则七月调改没有营业额。

一句话：对外两本账——小业主看 160，商户看带内承受力。一本账对外，街会死。

## 问 5. 最大 3 个风险

按「能把项目打死」排序，不按宣传。

**风险 1 — 返租刚性兑付（财务红）。**  
出租率或自营任一掉档，505.9 万仍要付。连续穿红区 = 欠小业主钱 = 1F 失控。没有比散售业主维权更能毁掉南门脸的事。

**风险 2 — 1F 货盘与产品反着来（经营红）。**  
宝藏星球 + 体育奥莱 + LBD 是吾悦的缩小版零售。手册、对标、1–2F 清退规则三条线都写：一层给局，不给衣服和奥莱。自营若按这三店做满，学年监测会把它们打成「A/B/C 都差或只逛不买」，但散售铺清不动——你自己就是承租人。自己给自己设套。

**风险 3 — 3# 出租率假满租（资产红）。**  
779 万是满租口径。教培一学期一空、政策一刀、或「中公粉笔」招满后暑假停课，出租率会在 7 月（返租照付、学生不在）最差。3# 若不能改出一部分全年办公/职训/MCN 后台，发动机不稳。

并列提醒（不进前三，但要写进备忘）：返租 9.6% 期满重定价；散售铺拒绝统一收银；5270 万被当成利润花掉后无兑付准备金。

## 问 6. 预算砍半怎么办

先问砍的是哪半。返租 505.9 **不能砍**（除非谈判降息或回购），一砍就是风险 1。

可砍的，按「保发动机、砍反着来的货盘」：

| 砍 | 做 | 不做 |
| --- | --- | --- |
| 7# 自营 | 三店收成 **1 个**；撤体育奥莱（与吾悦重复、寒暑假最伤）；货盘改餐/局或转租绿铺 | 砍一半存货还开三店 |
| 1F 占用 | 能转租出去的平方米立刻转；自营只留内容需要的窗口 | 为了「自营氛围」占满 2,635 ㎡ |
| 3# | **不砍招商人力**。出租率是命 | 为了省佣金让 3# 空 |
| 感知 / AI | 按白皮书三档降到 500 或以下，雷达保入口+广场 | 砍雷达保奥莱装修 |
| 夜场硬件 | 保广场和 LED，砍零售道具 | 砍广场保货架 |
| 散售 | 若还没卖完：降 返租承诺到 6–7% 或少卖，留下关键沿街 | 为了凑 5270 把整层 1F 卖光且 9.6% 锁死 |
| 现金 | 5270 里先划 **两年返租准备金** ≈ 1,012 万，再花剩余 | 散售回款当利润分红 |

砍半后的目标态（比现在健康）：

- 3# 出租率守 80%
- 自营利润按 **0** 做预算（273 当彩票）
- 净额按矩阵 **80% × 0 = 117 万** 活
- 1F 能转租的转租，缩小返租占用
- 产品回到南门夜场，不跟吾悦比货架

117 万很瘦，但比「账面 546、结构 0.54 覆盖」更诚实。活过返租期，比做满奥莱重要。

**给决策人的三步（按顺序）：**

1. 3# 出租率做成周报，红线 65%、操盘线 80%。
2. 管理账给 7# 自营记内部租金 160，看清谁在亏；三店先砍奥莱。
3. 5270 万划出两年返租准备金；剩余才许动。1F 能转给餐/局的尽快转，给七月调改留执行权。

本单不替代法务上的返租合同审查，也不改招商手册客群口径。数字以当场口径为准；铺位表和返租年限一到，升 v0.2 把 2,635 ㎡ 和 9.6% 换成合同数。
