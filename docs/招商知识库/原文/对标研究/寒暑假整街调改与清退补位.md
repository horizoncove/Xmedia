# 寒暑假整街调改与清退补位

| 项 | 值 |
| --- | --- |
| 版本 | v0.1（经营制度，非法务终稿） |
| 日期 | 2026-08-30 |
| 性质 | 整街调改，不是个别店「劝退」 |
| 上游 | 招商手册 v0.1 第 6 条 · 寒暑假操作系统 · 品牌意向池 |
| 一句话 | **寒暑假是调改窗口。不达标就清。清完当天有人接。留下的店，当季得有人给钱。** |

这不是保证每家赚钱。是保证：**还开着的店，面对的是还在的客人。** 客人走了还占铺，既坑自己，也坑整条街。

---

## 0. 原则（先跟商户说清楚）

1. **指标事先写进合同。** 开业后再宣布规则，清退打不成。签约当天发《指标卡》和《调改日历》。
2. **不达标就清，没有人情席。** 黄灯只给一次改的机会。红灯或拒改，进入清退。
3. **清和补是同一周的事。** 只清不补，街是空的，比差店更糟。空铺用快闪顶上，绿/黄意向店同步进场。
4. **调的是整街结构，不是单店情绪。** 目标是当季在营组合里，每家都对得上还在的钱包（暑假 = 白领/留校/内容；学期 = 学生夜+白领午）。
5. **减租只换开门和达标，不换占铺。** 关店、拒核销、拒工卡，不享受淡季条款。

对商户原话：

> 学期你靠学生。暑假学生回家，你要么交出暑假菜单并达标，要么把铺让给这个季节能挣钱的人。我们不会留一排关门卷帘过完 7 月。

---

## 1. 为什么必须整街调，不能「各自熬」

学生一走，红铺会集体亏。若只劝不退：

- 卷帘一排，热力更低，绿铺也被拖死
- 白领走进来像鬼街，工卡券核不出去
- 下学期开学，差店还占着好铺，好店进不来

所以寒暑假不是「挺一挺」。是 **结构重排**：减红、保绿、补能挣钱的。

开园年更狠：**2027-05-01 开园，约 8 周后暑假。** 手册里的「90 天调铺」会落到 7 月底，**来不及**。开园年用压缩日历（第 4 节）。

## 2. 指标卡（两套，签约就发）

没有铺位表、没有 POS 之前，**不写死流水门槛**。先用能测的：雷达热力、开门、合规、核销。铺位和收银接口到了，升 v0.2 加「日均成交笔数」。

### 2.1 一票否决（学期、寒暑假都算，碰一条即红灯）

| 项 | 不达标长什么样 |
| --- | --- |
| 校园价 | S 带没有学生套 / 核心 SKU 无 10–20% 差价 |
| 工卡午餐 | W 带工作日 11:00–14:00 无工卡套，或连续两周不接工卡 |
| 营业时段 | S 夜宵周五六不到 24:00；W 工作日午饭不开 |
| 统一核销 | 拒收街区券 / 联票（P、C 必接；暑假工卡夜券全街应接店拒接） |
| 禁入品类 | 转成孩子王、影院、大超、珠宝、沣西里同菜单清吧火锅等 |
| 内容墙 | 主视野自行封死，不让拍 |
| 虚假承诺 | 物料写「15 万师生 / 西工大校门口 / 6000 人日均吃饭」 |
| 连续停业 | 无批假停业 ≥7 天（春节骨架店除外） |

一票否决 **不走黄灯**，直接红灯，进入清退程序。

### 2.2 学期经营指标（用来决定暑假清谁）

观察窗：连续 **4 个完整经营周**。开园年第一窗见第 4 节。

| 指标 | 达标 | 黄灯 | 红灯 |
| --- | --- | --- | --- |
| **店前热力** | ≥ 同带中位的 70% | 50–70%，且已持续 4 周 | **< 同带中位 50%**，连续 4 周 |
| **应开未开** | 0–1 天/4 周 | 2–3 天 | **≥4 天** 或连续 2 周午饭（W）不开 |
| **核销配合** | 接券且有成交 | 接券但拒核销活动 | 拒接券 |
| **同带伤害** | 无 | 菜单与隔壁完全同质、互相挖 | 已黄灯一次仍不改 |

热力用感知最终版的雷达客流，按 **同带、同时段** 比，不跟吾悦比，不跟开业秀比。C 带（内容/快闪）不看热力红灯，看是否履约拍摄和档期。

### 2.3 寒暑假生存指标（当季就测，当季就清）

暑假观察窗：开学前公布的暑假时刻表执行周，连续 **2 周** 即可红灯（窗口短，不能等 4 周）。

| 指标 | 达标 | 红灯（当季清） |
| --- | --- | --- |
| 暑假菜单 / 第二产品 | 黄、红铺已交并上架 | 没交，或交了不上架 |
| 开门义务 | 绿铺工作日开；黄铺 ≥5 天/周 | 绿铺连续 2 个工作日不开；黄铺一周开不足 3 天 |
| 工卡夜券 | 应接店有核销 | 拒接 |
| 广场档期 | 排到的场到人、到灯 | 连续两次空场且店关 |
| 快闪服从 | 红铺同意减摊/短租叠层 | 占铺不开、拒绝叠层 |

寒假：考研周看 3# 配套热食和便利；春节 7 天只考骨架店是否留了一口热的。

### 2.4 「有希望挣钱」怎么验（调改后的街，不是单店承诺）

调改结束当天，招商负责人在白板上勾：

| 当季还在的钱包 | 街上至少要有 |
| --- | --- |
| 园区午饭 | ≥3 家工卡简餐/面在开 |
| 白领下午/夜 | ≥1 咖啡 + ≥1 能坐的清吧或夏夜摊 |
| 留校考研 | 24h 便利 + 1 热食 + 3# 自习开 |
| 内容 | MCN 工位开、主视野能拍 |
| 周末夜 | ≥1 个 P 带在开（包场或电竞/台球） |

缺一项，说明补位没完成，**调改不算收口**。  
不在表上的店（纯学生饰品、第三家同质烤摊）暑假不应还在硬撑。

不承诺「每家日进 8000」。承诺的是：**没客人的品类，不留在当季的街上。**

## 3. 处置：留 / 改 / 清

| 灯 | 谁 | 做什么 | 时限 |
| --- | --- | --- | --- |
| **绿灯** | 指标达标 | 留。可给淡季条款（减租换开门） | — |
| **黄灯** | 学期热力 50–70%，或同质、或暑假菜单弱 | **只改一次**：换菜单 / 换时段 / 并摊 / 换带。书面整改单 | **14 天** 改完，再测 2 周 |
| **红灯** | 一票否决，或热力 <50%×4 周，或黄灯到期仍不达标，或寒暑假生存指标红 | **清退。** 不续、不转禁入品类、不养着过暑假 | 见日历：通知 → 腾铺 → 快闪顶上 |

黄灯用完了就是红灯。没有第二次黄灯。  
红灯商户可以申请 **自己换成绿品类**（例如烤摊改工卡面）。7 天内交出可开业方案并在约定期限开出来，视为改而不是清。开不出来，仍清。

清退不是没收设备跑路。流程：

1. 书面红灯通知（合同已授权的调改条款）
2. 腾铺期：**学期清退 15 天；寒暑假清退 7 天**（铺要马上给能挣钱的人）
3. 押金、未摊装修按合同；拒腾按占用条款
4. **腾铺日 = 快闪或新商户进场日**，中间不允许黑铺超过 48 小时（清洁+进场）

## 4. 日历：谁在哪一天被清、谁在哪一天进来

### 4.1 开园年压缩（2027，必须用这个）

手册「90 天调铺」对开园年太晚。用这条：

| 日 | 动作 |
| --- | --- |
| 签约时 | 发指标卡、抗跌色、本日历。商户签字 |
| **05-01** | 开园。雷达按带出日报 |
| **05-31** | T+30：内部预警名单（不对外清） |
| **06-14** | T+45：**黄灯书面发出**。只改一次，14 天 |
| **06-28** | T+58：黄灯复测。仍不达标 → **红灯** |
| **06-30 前** | 红灯通知 + 暑假补位意向店草签（绿/黄池） |
| **07-05 前** | 红灯腾铺。快闪或新店进场。暑假时刻表上墙 |
| 07 月中–8 月底 | 按寒暑假生存指标 **再清一轮**（开门义务、拒券、空场） |
| **08-20 前** | 暑假红灯清完；开学迎新铺位锁定 |
| **08 月底–09 上** | 迎新。新一学期指标窗重新计 |

毕业季（5–6 月）热力会偏高，**不要用开业秀周当中位**。中位从开园第 3 周开始算。

### 4.2 稳定年（2028 起）

| 窗口 | 动作 |
| --- | --- |
| 学期第 8 周 | 黄灯预告 |
| 学期第 10 周 | 黄灯发出 |
| 放假前 3 周 | 红灯确认、补位草签 |
| 放假第 1 周 | 腾铺 + 快闪/新店 |
| 假期中每 2 周 | 生存指标复盘，不达标当季再清 |
| 开学前 10 天 | 调改收口，验「有希望挣钱」五件套 |

寒假执行同样逻辑，腾铺期仍是 7 天；春节骨架店不在这轮清（只考有没有热食）。

## 5. 补谁进来（清完必须有人）

补位 **只从能在当季挣钱的池子进**，不是谁出价高给谁。

### 5.1 暑假优先补（绿 → 黄）

P0 缺口按这个顺序补，补满再谈红铺回填（红铺回填默认等到开学）：

1. 24h 便利（若空了，第一优先）
2. 工卡简餐 / 面 / 西北快餐
3. 平价咖啡（库迪/幸运咖/瑞幸标准店）
4. 台球/飞镖/电竞（低人力）
5. 剧本杀/密室的 **企业包场档**（原店能改就改，不能改就换运营方）
6. 夏夜市集摊（白领套，不是第三家同质烤）
7. MCN 工位、快闪（雪糕、拍摄、运动体验）

### 5.2 开学优先回填（可以回一点红）

迎新 10 天需要茶、夜宵、拍照。暑假清掉的烤摊/蜜雪，**可以开学再进来**，但是：

- 仍要签指标卡
- 全街红铺面积仍 ≤ 25%，S 带红铺仍 ≤ 一半
- 上一个暑假红灯且拒改的主体，**下一学期不优先原铺**（避免占坑）

### 5.3 快闪顶铺（48 小时规则）

腾铺后 48 小时内必须出现下列之一：

- 已草签的绿/黄店进场装修（围挡上写「×月×日开」）
- 或 6–8 周快闪营业
- 或业主自营摊（工卡夜、电影夜的酒水/热食）

禁止：白灯、锁门、堆杂物过一周。

## 6. 合同要补的句子（给法务，不是终稿）

在手册 8 条 + 寒暑假 6 条之外，调改再写 7 句：

1. 承租人确认已收取《指标卡》和《调改日历》，同意按热力、开门、核销、一票否决项接受黄灯/红灯。
2. 黄灯仅一次，整改期 14 天；到期未达标视为红灯。
3. 红灯时出租人有权提前终止该铺经营，学期腾铺 15 日，寒暑假腾铺 7 日。
4. 出租人有权在腾铺后立即安排快闪或新承租人；原承租人不得阻碍。
5. 寒暑假生存指标独立计算，不影响学期已形成的红灯。
6. 开园年适用压缩日历（T+45 黄灯 / 放假前红灯）；与普通 90 日条款冲突时，以开园年日历为准。
7. 指标中位、同带对比方法以街区公示的雷达口径为准；承租人可申请复核一次，复核不停止腾铺时限。

租金、违约金、装修残值 **本版不写死**，法务按当地成交补。经营原则已经够清：不达标就清，清完有人接。

## 7. 谁拍板、谁执行

| 角色 | 权 |
| --- | --- |
| 招商负责人 | 黄灯/红灯签发；补位品牌是否绿/黄 |
| 运营（含感知） | 每周出同带热力表、开门表、核销表 |
| MCN / 内容 | C 带履约、广场档期到人 |
| 法务 | 通知函、腾铺、阻碍 |
| 董事会 | 只看两件事：红铺面积有没有压下来；「有希望挣钱」五件套缺不缺 |

单店求情不进董事会。结构数字进。

## 8. 对内对外各一句

**对内：** 寒暑假是整街换挡。用指标清红铺，用绿池补位，用快闪填 48 小时空窗。留下的每家都要对着还在的客人。

**对外（商户）：** 达标就留，黄灯改一次，不达标就清。我们把铺交给这个季节能挣钱的人——包括你，如果你改得出来。

**对外（补位商户）：** 现在进的是暑假/寒假能做的生意（工卡、便利、面、包场、拍摄），不是来熬学生。开学另有一波铺，不跟你抢当季的客人。

## 9. 还缺什么（升 v0.2）

- 铺位表：按号打抗跌色、带、雷达点位
- 雷达日报模板：同带中位自动出
- 法务：《指标卡》《红灯通知》《腾铺确认》三张纸
- 补位意向库：绿/黄店随时可进的 10 个主体（没有库，清了是空街）
- 商贸校历：把第 4 节日期钉死

没有补位库就开清，等于自残。**先把 10 个可进主体谈成框架，再发出第一张黄灯。**
