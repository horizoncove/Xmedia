# 学年监测 × 一年一签 × 七月调改

| 项 | 值 |
| --- | --- |
| 版本 | **v0.2**（按决策人口径改过；非法务终稿） |
| 日期 | 2026-08-30 |
| 性质 | 整街年度调改，不是开园 8 周就清场 |
| 上游 | 招商手册 v0.1 · 寒暑假操作系统 · 品牌意向池 |
| 一句话 | **合同一年一签。八月底九月初开学起，家家盯营业额和客流。营收/利润好的留；营收一般但客流高的也留。两项都差的，五月预警，七月清，马上补能挣钱的。** |

v0.1 写成「开园后 45 天黄灯、第一个暑假就清」。那是错的。决策人要的是 **满一个学年再调改**。寒暑假操作系统（夏夜换皮、工卡夜券）照旧；**清退窗口在次年七月，不在开园当年 7 月。**

---

## 0. 周期（先钉死）

```
8 月底 / 9 月初 开学
    → 开始逐店监测营业额 + 客流
    → 过秋、冬、春（含寒假，数据照记）
次年 5 月
    → 书面预警（黄灯）：两项都弱的店
次年 7 月
    → 调改：续签一年 / 清退 / 补位
8 月底
    → 新店迎新，下一学年监测重新计
```

第一轮完整监测：**2027-09-01 → 2028-07**。  
2028-05 发预警，**2028-07 第一次整街调改**。

开园 2027-05-01 到 2027-08 底：雷达和收银可以先跑，**不进清退分**。用来校口径、找同带中位，不当第一刀。2027 暑假只做换皮和开门，不按年度调改清场。

一票否决（停业、拒券、转禁入品类）任何时候可以清，不等七月。

---

## 1. 合同：每家签一年

| 规则 | 口径 |
| --- | --- |
| 租期 | **默认 12 个月**，到期日尽量卡在 **7 月 31 日** |
| 首批（2027-05-01 开） | 签到 **2028-07-31**（约 15 个月），为的是赶上第一轮七月调改，不要 2028-04 到期、七月还在打官司 |
| 续签 | 达标 → **优先续 12 个月**（1+1）。装修才敢投 |
| 不达标 | 七月不续，7 天腾铺 |
| 连锁要 3 年 | 可以谈 **1+1+1**，每年仍过指标；不接受「三年锁死、不考核」 |
| 抽成 / 保底 | 一年一签照旧可以抽成；抽成是监测营业额的接口，不是让你养三年 |

对商户原话：

> 我们按学年跟你过。九月起看你的营业额和门口人。你好好做，七月优先续一年。两项都差，五月先告诉你，七月到期不续。铺留给能把人带来、能把钱留下的店。

---

## 2. 留谁：两条腿，中一条就留

每店每月出两列，学年末算总。

| 腿 | 测什么 | 达标（建议，v0.2 用相对数） |
| --- | --- | --- |
| **A 挣钱** | 营业额；利润能核的核，核不了用租售比/抽成额当代理 | 学年营业额 ≥ **同带中位 70%**；或抽成/报来的毛利明显好于同带（抽查） |
| **B 带人** | 店前雷达客流（感知最终版，同带同时段） | 学年店前客流 ≥ **同带中位 70%** |

### 留 / 警 / 清

| A 挣钱 | B 带人 | 结果 |
| --- | :---: | --- |
| 好 | 好 | **留，优先续一年** |
| 好 | 一般/差 | **留**（赚钱店，不赶） |
| 一般/差 | 好 | **留**（引流店：蜜雪、出片茶、广场磁铁）。可谈低固定+高抽成，用它给人流 |
| 差 | 差 | **五月预警，七月不续** |

「利润高」业主账上看不全。本版执行：

1. 能接收银 / 抽成的，用流水和抽成额
2. 暂不能接的，商户每月报营业额，抽查进货和核销
3. 利润只作 **加分**（报得清且抽查对得上），不作唯一留铺门槛  
   真正的留铺门槛是：**A 或 B 至少一条达标。** 两条都差，清。

一票否决仍直接清，不走五月预警：

- 无校园价（S）/ 无工卡套（W）
- 该开不开、拒街区券
- 转成禁入品类
- 物料写「15 万师生 / 西工大校门口 / 6000 人日均吃饭」
- 无批假连续停业 ≥7 天（春节骨架除外）

C 带（MCN、快闪）不看营业额红灯，看档期和拍摄履约。履约即留。

## 3. 监测：从开学盯到次年七月

| 谁 | 交什么 | 频率 |
| --- | --- | --- |
| 运营 + 雷达 | 店前客流、同带中位、开门天数 | 周报；月度进册 |
| 商户 | 月营业额（接收银的自动出） | 次月 5 日前 |
| 招商 | 更新 A/B 两列灯 | 每月 |
| 核销 | 券成交笔数（辅助，证明人是真来的） | 月 |

开学首 2 周、毕业周、开业秀周 **不进中位**，避免把迎新高峰当成日常。寒暑假的营业额和客流 **照记**，它会拉低纯学生店的学年总分——这是故意的：只会做学期、暑假卷帘的店，B 和 A 都会难看。

每月对商户可见一页：本店营业额、本店客流、同带中位、目前 A/B 灯。五月不要突然袭击。

---

## 4. 五月预警，七月调改

### 4.1 五月（预警，不是清场）

对「A 差且 B 差」的店发书面黄灯，内容必须有：

- 开学至今的营业额、客流、同带中位
- 差在哪一条
- 6 月还可以补：换菜单、加班段、接券、并摊
- 写明：七月到期 **默认不续**；6 月两项都拉回 70% 可以申请复议一次

黄灯不是 14 天滚蛋。是 **还有一个完整月把数做回来**。

### 4.2 七月（调改）

| 动作 | 时间 |
| --- | --- |
| 锁定续签名单 / 不续名单 | 7 月第一周 |
| 续签店签下一学年（到次年 7-31） | 7 月内 |
| 不续店腾铺 | **7 日内** |
| 补位店进场或快闪顶上 | 腾铺后 **48 小时** 内有围挡或开业 |
| 新组合迎新准备 | 8 月 |
| 下一学年监测归零 | 8 月底 / 9 月初 |

七月清完要验街上还在的店：续签的要么能挣钱，要么能带人。两项都差的不应还在。

补位优先绿/黄池（便利、工卡面、咖啡、能包场的局、MCN）。出价高但 A、B 都讲不清的，不补。

## 5. 2027–2028 第一轮日期

商贸校历未入库，日期按陕西高校中位，开园后换成商贸校历。

| 日 | 动作 |
| --- | --- |
| 2027-05-01 | 开园。雷达、收银试跑。**不计清退分** |
| 2027-07–08 | 暑假换皮（工卡夜、电影、开门）。不做年度清场 |
| **2027-08 底 / 09 初** | **监测元年开始**。家家出 A/B |
| 2027-09–2028-04 | 月报。商户能看见自己的灯 |
| **2028-05** | 对 A 差且 B 差的店发预警 |
| 2028-06 | 整改月 |
| **2028-07** | 续签或清退补位。合同签到 2029-07-31 |
| 2028-08 底 | 迎新。监测重新计 |

之后每年重复：九月计、五月警、七月改、一年一签。

## 6. 寒暑假还干什么（和七月调改分开）

寒暑假操作系统不废。它管的是 **街上干什么**，不管 **年度谁出局**。

- 暑假：换工卡夜券、减红摊、电影/园区局、绿铺必须开门
- 寒假：考研热食、年会包场、春节骨架
- 暑假卷帘、拒工卡的店：记进学年 A/B（客流和营业额会差），五月更容易进预警
- 只有一票否决，才在假期中途清

不要把「七月年度调改」和「暑假换皮」混成一次运动。

## 7. 合同要补的句子（给法务）

1. 租期 12 个月，到期日为 7 月 31 日；开园首批到期日为 2028 年 7 月 31 日。
2. 出租人从当年 8 月 31 日或开学日起监测营业额与店前客流；承租人应按月提供营业额或接入指定收银。
3. 学年内营业额或店前客流任一达到同带中位 70% 的，期满优先续租 12 个月。
4. 两项均未达到同带中位 70% 的，出租人于 5 月书面预警，7 月到期可不再续租。
5. 一票否决事项（拒校园价/工卡、拒核销、禁入品类、擅自停业等）出租人可提前终止，不等 7 月。
6. 不续租的，承租人于到期后 7 日内腾铺；出租人可立即安排新承租人或快闪。
7. 三年总意向可写成 1+1+1，每一期续租以当年指标为前提。

装修残值、违约金本版不写死。一年一签能签出去，靠的是第 3 条 **达标优先续**，不是靠三年死约。

## 8. 谁拍板

| 角色 | 权 |
| --- | --- |
| 运营 + 雷达 | 客流、开门、同带中位 |
| 招商 | 营业额册、五月预警、七月续签/不续 |
| 法务 | 一年租约、预警函、腾铺 |
| 董事会 | 只看：一年一签有没有坚持；七月清掉的是不是「A 差且 B 差」；补位 48 小时有没有空街 |

求情不进董事会。A/B 两列数字进。

## 9. 对内对外

**对内：** 学年记账，七月换挡。挣钱的留，带人的留，两头空的到期不续。

**对外：** 九月开始计。你好好做，七月续一年。又没流水又没人，五月先通知，七月到期请让铺。

## 10. 还缺什么（升 v0.3）

- 收银 / 抽成接口（没有它，营业额靠自报，要抽查）
- 同带中位的自动月报
- 法务三张纸：一年租约、五月预警函、七月不续+腾铺
- 七月补位库：至少 10 个可在 8 月开业的主体
- 商贸校历：把「八月底九月初」钉成具体日

**先把一年一签和开学监测写进每一份意向，再谈品牌。** 品牌池仍然用，但进场都知道：做满一学年，七月见。
