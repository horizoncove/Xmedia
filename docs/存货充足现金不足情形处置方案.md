# 存货充足、现金不足情形下的债务处置方案

**适用情形（已明确口径）：**

| 项目 | 金额（万元） | 说明 |
| --- | --- | --- |
| 存货货值 | 8,000 | **现房，已具备办证条件** |
| 应收账款 | 2,500 | 客户按揭待回款、未付购房款 |
| 可变现资产小计 | 10,500 | 账面覆盖口径 |
| 工程款 | 5,800 | 最大债权人，可能享有建设工程价款优先受偿权 |
| 应缴城建配套费 | 1,900 | **城市建设配套费，交住建局**；办证 / 过户行政卡点 |
| 欠付供应商 | 500 | 材料/设备等普通经营债 |
| 退房款 | 120 | 金额小但维稳敏感，建议优先现金清 |
| **已知负债合计** | **8,320** | 若另有民间借贷、税费、诉讼债等，请补录 |
| 银行抵押 | **无** | 重大有利条件：过户、抵债障碍小 |
| 现金 | 严重不足 | 核心矛盾仍是流动性 |

> 若此前口径“累计负债约 10,000 万”，与已知 8,320 万之间约有 **1,680 万** 差额，请尽快核实是否含利息罚息、其他往来、税费或或有负债。下文按 **已知 8,320 万** 设计，并预留差额处理口子。

---

## 一、形势判断（更新）

当前盘面比一般房企困境**明显更好**，原因有三：

1. **无银行抵押**：销售过户、以房抵债不必先解押，效率高；
2. **现房且可办证**：对施工方、供应商吸引力强，抵债可落地；
3. **账面资产 10,500 对已知负债 8,320**，覆盖约 **1.26 倍**。

真正卡点只有两个：

1. **没现金**，无法同时兑付工程款与配套费；
2. **配套费 1,900 万** 若不解决，办证/过户可能受阻，则“可抵债”优势落空。

**结论：**  
最优路径不是破产清算，而是：

> **先用小钱打通办证 → 再大规模以房抵工程款 → 销售和应收回收补现金 → 小额债尽快清掉。**

预重整不是首选；优先 **庭外分类和解**。只有出现大面积查封、工程方拒绝抵房并坚持拍卖时，再转预重整。

## 二、总策略（按本负债结构定制）

```text
应收清收 2,500
    +
存货销售变现（约 2,500—3,500 货值）
    ↓
形成现金池，优先用于：
  ① 退房款 120
  ② 配套费（全部或换取办证的最低额度）
  ③ 少量供应商折扣清偿 / 工程续尾必要支出
    ↓
剩余存货（约 4,500—5,500 货值）
    ↓
主要用于抵偿工程款 5,800
```

## 三、四类债务的具体处置

### 3.1 退房款 120 万——最先清

| 项 | 安排 |
| --- | --- |
| 性质 | 敏感、涉稳，拖延成本高于金额本身 |
| 方式 | **全额现金**，争取 30 日内清零 |
| 资金来源 | 应收清收首笔到账 / 首批售房回款 |
| 目标 | 消除信访与诉讼点火点，换取谈判环境 |

### 3.2 城市建设配套费 1,900 万（住建局）——第二优先

**费用定性：** 应交给**住建局**的城市建设配套费，属于行政性收费 / 政府性基金类义务，不是普通供应商欠款。

实务上它决定：

- 住建 / 不动产登记是否放行分户与转移登记；
- 总包以房抵债能否过户交割；
- 新售客户与按揭放款能否闭环。

**对住建局的争取顺序：**

1. **首选：** 随过户逐套缴纳（办一套、缴一套）；  
2. **次选：** 先缴 600—900 万开通办证，余款 6—18 个月分期；  
3. **升级：** 窗口无权灵活安排时，报政府化解专班做府院 / 部门联席；  
4. **保底：** 一次性 1,900 万（仅在前三条都谈不成时，用应收+急售硬扛）。

**会谈话术核心：**  
灵活缴费可加快办证、去化与税源落地；一次逼清将抽干现金，导致总包和解失败和业主办证停滞，反而扩大不稳定因素。

> 详细申请书提纲、缴费模型与 10 个工作日动作，见：`docs/城市建设配套费缴纳与办证沟通要点.md`  
> 没有住建局放行路径，工程款以房抵债谈不成；城建配套费是全局杠杆点。

### 3.3 工程款 5,800 万——集中总包一家，签一揽子和解

**关键事实：工程款债权人仅为施工总包一家。**  
这是本案最大利好之一：不必开债委会、不必平衡多家分包，**一场专谈就能锁定 70% 已知负债**。

因 **无抵押 + 现房可办证 + 单一总包**，应以 **“一套协议解决全部工程款”** 为谈判目标：以房抵债为主、少量现金为辅、余款短分期。

**推荐对总包的报价结构（开口可谈）：**

| 方式 | 金额（万元） | 说明 |
| --- | --- | --- |
| 以房抵债 | 4,500—5,200 | 现房按协商价抵减工程本金（可略优于市场急售折扣） |
| 签约现金头款 | 300—500 | 签约后 15—30 日付，换停诉、撤查封、配合办证 |
| 分期留债 | 300—800 | 12—18 个月，按后续销售回款比例偿还 |
| 合计覆盖 | 5,800 | 力争一次包圆，不留尾巴纠纷 |

**专谈节奏（建议 21 天内谈成框架）：**

1. **第 1 周**：内部定抵债房源包（房号、面积、挂牌价、拟抵债价）；向总包发出《一揽子和解要约》；
2. **第 2 周**：对结算金额定案（或先签“暂定债权额 + 多退少补”），看房选房，谈单价与过户时点；
3. **第 3 周**：签《一揽子和解及以房抵债协议》+ 共管账户文件；同步撤诉/暂缓执行。

**必须写进协议的条款：**

1. **债权一次性确认**：确认应付工程款总额（含是否含质保金、奖罚、签证）；  
2. **清偿方式封闭**：房抵 + 现金头款 + 留债分期 = 全部工程债权，其余主张归零或放弃；  
3. **停诉停执**：已诉撤诉/中止，未诉不起诉，已查封的强制措施配合解除；  
4. **优先受偿权处理**：在已获抵债与现金对价范围内，不再就同一债权申请拍卖优先受偿；  
5. **分包与劳务消化**：总包承诺自行消化分包、材料、农民工工资，不向开发商重复追索；  
6. **过户配合**：开发商负责办证过户路径，总包按约定时间接收并承担约定税费；  
7. **违约救济**：任一方违约，已抵房产与已付款如何处理、加速到期条款。

**总包为什么更可能接受（谈判话术）：**

- 债权人只有他一家，方案可以“量身定做”，不必被其他债权人摊薄；  
- 现房、无抵押、可办证，拿房比拍卖快、折价小；  
- 给现金头款 + 可售现房，比打几年官司回收率通常更高；  
- 分包和农民工由其内部消化，避免群体事件反噬总包自身。

> 详细协议提纲见：`docs/总包工程款一揽子和解及以房抵债协议要点.md`

### 3.4 供应商 500 万——小额清 + 部分抵房

| 分层 | 标准 | 方式 |
| --- | --- | --- |
| 小额 | 单户 ≤ 20 万 | 现金折扣一次性清（如 7—9 折） |
| 中大额 | 单户 > 20 万 | 部分现金 + 车位/小户型抵债，或 6—12 个月分期 |

目标：3 个月内基本清完，避免供应商诉讼干扰过户。

## 四、资产端怎么配合

### 4.1 应收账款 2,500 万

| 动作 | 目标 |
| --- | --- |
| 已批未放按揭 | 30 日内催放 |
| 有能力未付尾款 | 45 日内折扣结清或转诉 |
| 疑难款 | 转诉讼 / 解除后续售 |

**回收目标：** 6 个月内到账 **1,500—2,000 万**，优先顺序：退房款 → 配套费 → 工程和解现金头款 → 供应商小额清。

### 4.2 现房存货 8,000 万（无抵押）

建议切成三包：

| 房源包 | 货值规模 | 用途 |
| --- | --- | --- |
| A. 急售变现包 | 2,500—3,500 | 定价可下浮 5%—10%，换现金缴配套费、清小债 |
| B. 工程抵债包 | 4,000—5,000 | 专供施工方一揽子抵债 |
| C. 机动包 | 500—1,000 | 供应商抵债、后续销售补缺口 |

因已是现房可办证，**不要大幅度贱卖**；真正该让利的场景是换取工程方整体和解与停诉。

## 五、一张总账（基准情景）

| 项目 | 金额（万元） | 结果 |
| --- | --- | --- |
| 应收回收 | 1,800 | 现金流入 |
| 急售变现（货值约 3,000，折扣后） | 2,700 | 现金流入 |
| **现金池合计** | **4,500** | — |
| 支用：退房款 | −120 | 清零 |
| 支用：配套费 | −1,900（或先付 800 + 分期 1,100） | 打通办证 |
| 支用：工程现金头款 | −400 | 换取抵债协议 |
| 支用：供应商现金 | −250 | 小额清 + 部分现金 |
| **现金池结余** | **约 1,830**（若配套费全额付） / 更高（若分期） | 用于留债与机动 |
| 工程以房抵债 | 4,500—5,000 | 大幅削债 |
| 供应商/其他抵债 | 150—250 | 削债 |
| 工程留债分期 | 500—900 | 随后续销售偿还 |

**基准结果：**  
已知 8,320 万负债可在 6—12 个月内降到 **零星留债 + 配套费分期尾款** 水平；企业保留少量尾盘继续销售。

### 压力情景（应收只收回 1,200、急售不畅）

- 必须把更多存货划入抵债包；
- 配套费务必谈成“过户时逐套缴纳”，避免一次性现金压垮；
- 工程款现金头款降到 200—300，主要靠房抵。

## 六、90 天行动表

| 周次 | 关键动作 | 产出 |
| --- | --- | --- |
| 第 1—2 周 | 房源三包划分；应收逐户清单；向住建局申请城建配套费分期/随过户缴；约谈总包 | 停火意向 + 办证路径确认 |
| 第 3—4 周 | 清退房款；收首笔按揭；取得住建局书面意见或专班纪要 | 办证通道打开 |
| 第 5—8 周 | 推出急售包；签署工程一揽子以房抵债协议；启动批量过户 | 工程债下降过半 |
| 第 9—12 周 | 供应商分层清偿；工程留债协议落地；剩余房源去化 | 已知负债主体落地 |

## 七、要不要预重整？

| 情形 | 建议 |
| --- | --- |
| 工程方接受抵房、配套费可分期/随过户缴、无大面积查封 | **庭外和解即可**，更快更省 |
| 工程方坚持全额现金、已申请拍卖、或多家同时执行 | **启动预重整**，用整体方案约束，并把抵债与办证安排写入协议 |
| 住建局拒绝任何灵活安排且硬性阻断办证 | 升级政府化解专班联席协调；仍不成再评估预重整 |

对本案：**先按庭外“办证 + 抵债”推进；同步准备预重整底稿，作为谈判备手。**

## 八、执行清单（按本结构）

1. 到住建局核清城建配套费欠费、滞纳金，书面确认是否阻断办证、可否随过户/分期缴纳；  
2. 列出可立即过户的现房清单（房号、面积、货值、成本）；  
3. 切分 A 急售包 / B 工程抵债包 / C 机动包；  
4. 退房款 120 万单列，首笔回款优先支付；  
5. 与施工总包谈：抵债额度、单价、停诉、结算定案；  
6. 应收 2,500 万按揭台账化，按周催放；  
7. 供应商按金额分层，出台折扣现金政策；  
8. 销售回款进共管账户，支出顺序写死；  
9. 核查是否还有约 1,680 万其他负债未入表；  
10. 若 30 日内工程方或配套费谈崩，立即转预重整文本。
