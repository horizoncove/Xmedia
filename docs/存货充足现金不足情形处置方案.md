# 存货充足、现金不足情形下的债务处置方案

**适用情形（当前测算口径）：**

| 项目 | 金额（万元） | 说明 |
| --- | --- | --- |
| 存货货值 | 8,000 | 现房 / 准现房 / 可售物业等，按对外可售货值口径 |
| 应收账款 | 2,500 | 客户按揭待回款、未付购房款等 |
| 可变现资产小计 | 10,500 | 账面覆盖口径，非即时现金 |
| 累计负债 | 10,000 | 含金融债、工程款、往来款等（需再拆分） |
| 现金 | 严重不足 | 核心矛盾：资产有、现金无 |

---

## 一、先看清形势：不是资不抵债，而是流动性断裂

按现有数字粗算：

- **账面覆盖倍数** ≈ 10,500 / 10,000 = **1.05 倍**
- 表面看资产略多于负债，**不宜直接走清算思维**
- 真正的风险是：
  1. 存货变现慢，折扣后可能掉到 6,000—7,200 万；
  2. 2,500 万应收存在按揭审批、客户违约、诉讼执行风险；
  3. 债权人逼债、诉讼查封会进一步压低去化价格；
  4. 若无序低价甩卖 + 利息罚息滚存，很快会从“账面平衡”滑向“实质资不抵债”。

**结论：**  
当前最优路径是 **“停火谈判 + 加速去化 + 应收攻坚 + 分类清偿”**，而不是简单破产清算。是否启动预重整，取决于未来 30—90 天能否与主要债权人达成展期/以房抵债安排。

---

## 二、处置总策略（一句话）

> **用 8,000 万存货去化 + 2,500 万应收清收，覆盖 10,000 万负债；先换时间，再换空间，避免被个别债权人撕破盘面。**

具体拆成四条线并行：

1. **应收账款 2,500 万：最快的现金来源，30 天内攻坚**
2. **存货 8,000 万：分层去化，一部分变现、一部分抵债**
3. **负债 10,000 万：分类重组，能展期的展期、能抵债的抵债**
4. **程序选择：能协商就庭外重组；谈不成再预重整**

---

## 三、三十天应急动作（先活下来）

### 3.1 立刻摸清三张表

1. **存货明细表**：楼栋/房号、面积、货值、成本、是否抵押、是否查封、去化难度分级  
2. **应收明细表**：购房人、应付余额、按揭银行、卡点原因、预计回款日  
3. **负债明细表**：债权人、本金利息、是否担保、是否诉讼、到期日、是否关联方  

没有这三张表，任何谈判都没有抓手。

### 3.2 与主要债权人签署“临时停火”安排

目标：争取 **90—180 天** 执行宽限期，期间：

- 不新增起诉、不申请拍卖核心可售存货；
- 暂缓宣布提前到期；
- 同意销售回款进入共管账户，按约定顺序使用。

### 3.3 资金进入共管 / 监管账户

回笼资金使用顺序建议：

1. 必要交房、办证、维修、解除按揭障碍的费用；  
2. 推动去化必须的营销与办证成本；  
3. 有抵押债权人的约定清偿；  
4. 工程优先款与职工必要支出；  
5. 普通债权人按协议比例清偿。

---

## 四、资产端怎么处置

### 4.1 应收账款 2,500 万：第一优先级

按可回收性拆成三类：

| 类别 | 特征 | 动作 | 目标回收 |
| --- | --- | --- | --- |
| A. 按揭已批未放 | 银行手续差临门一脚 | 专人盯银行、补材料、协调放款 | 力争 30 日内到账 |
| B. 客户有能力未付款 | 尾款/节点款拖欠 | 发催收函、协商折扣结清、必要时诉讼/解除合同转售 | 45—60 日 |
| C. 疑难应收 | 客户失联、拒付、假按揭嫌疑 | 法律追索 + 准备转存货二次销售 | 保守折扣计提 |

**建议目标：**  
2,500 万应收，争取 **6 个月内回收 1,500—2,000 万现金**；其余转诉讼或转存货处置。

### 4.2 存货 8,000 万：分成“卖、抵、换、养”四条路径

| 路径 | 适用存货 | 操作要点 | 对负债的作用 |
| --- | --- | --- | --- |
| **卖**（现金去化） | 刚需、去化快、无复杂查封 | 定价可较货值下浮 5%—15%，换真金白银 | 直接降负债、补现金 |
| **抵**（以房抵债） | 改善型、商办、车位、去化慢 | 与工程方、民间债权人、部分金融机构协商按评估/协商价抵债 | 快速削负债，少占现金 |
| **换**（置换过户/包销） | 大宗尾盘 | 引入包销商、当地国企/中介包销，支付佣金或锁价包销 | 缩短去化周期 |
| **养**（暂缓） | 被抵押且债权人同意支持销售的优质资产 | 不贱卖，随销售进度还款 | 保护剩余价值 |

#### 建议的存货处置量化目标（6—12 个月）

假设货值 8,000 万：

| 处置方式 | 规模（货值） | 预计回收/削债效果 |
| --- | --- | --- |
| 市场化销售（含适度折扣） | 3,500—4,500 万 | 现金约 3,000—4,200 万 |
| 以房抵债 | 2,500—3,500 万 | 直接削减负债约 2,200—3,200 万（按抵债定价） |
| 暂留待售 / 后续清收 | 1,000—1,500 万 | 作为偿债储备 |

> 注意：以房抵债定价通常低于对外挂牌货值；要用“削债金额”而不是“货值”来衡量成效。

### 4.3 避免三个致命错误

1. **无序低价甩卖**：个别债权人施压下 ind 拍卖，可能按货值 5—6 折成交，整体盘面被打穿；  
2. **回款不进专户、被挪用**：一旦失信，债委会谈判立刻破裂；  
3. **先还人情债、关联债**：后续预重整/重整中极易被撤销，并引发刑事责任风险。

## 五、负债端怎么重组（10,000 万怎么切）

先把 10,000 万负债拆开（请按实际替换）：

| 债权类别 | 假设占比 | 金额（示例） | 处置原则 |
| --- | --- | --- | --- |
| 有抵押金融债权 | 40% | 4,000 | 销售回款优先还；可展期；支持带押销售 |
| 工程款 / 优先受偿 | 20% | 2,000 | 一部分现金续建/收尾，一部分以房抵工程款 |
| 普通金融 / 民间借贷 | 25% | 2,500 | 展期 + 降息 + 部分以房抵债 + 少量现金 |
| 供应商、小额债 | 10% | 1,000 | 小额一次性折扣清、大额分期或抵房 |
| 关联方 / 股东借款 | 5% | 500 | 劣后、减免或转股 |

### 5.1 推荐重组结构（针对本表）

在“存货 8,000 + 应收 2,500、负债 10,000、现金紧”的约束下，较稳妥的组合是：

1. **现金清偿池 4,500—5,500 万**  
   来源：应收清收 1,500—2,000 + 存货销售 3,000—4,000  
2. **以房抵债削债 2,500—3,500 万**  
3. **留债展期 2,000—3,000 万**  
   期限 3—5 年，宽限期 6—12 个月，利率降至约定低息或阶段性停息挂账  
4. **关联债权减免 / 劣后 500 万左右**

这样可以在不依赖大额新融资的前提下，把即期兑付压力压到可承受区间。

### 5.2 对不同债权人的谈判话术要点

- **银行/抵押债权人：** “同意带押销售 + 回款进共管户，比司法拍卖回收更高、更快。”  
- **施工方/供应商：** “现金比例有限，提供可过户现房抵债，并协助办证，优于长期挂账。”  
- **民间借贷：** “给三种菜单——折扣现金、分期留债、以房抵债，三选一或组合。”

## 六、要不要上预重整？

### 6.1 可以先庭外重组的信号

- 主要债权人（尤其抵押行）愿意给 3—6 个月宽限；  
- 存货多为现房、权属清晰、能办证；  
- 应收 2,500 万中大部分可在短期内回收；  
- 没有大规模群体性交付/维稳风险。

### 6.2 建议启动预重整的信号

- 已出现多起查封、冻结、网拍；  
- 个别债权人拒绝停火，准备 aggresive 执行；  
- 交叉违约已经触发；  
- 需要“全体债权人一体约束”才能避免被拆散拍卖。

**对本案的建议：**  
先用 **15—30 天** 做庭外“停火 + 去化 + 清收”；若主要债权人达不成书面安排，再迅速转入预重整，把已经谈好的以房抵债、共管账户、展期条款固化进预重整协议。

## 七、十二个月实施节奏

| 阶段 | 时间 | 关键成果 |
| --- | --- | --- |
| 止血期 | 第 1 个月 | 三张表、共管账户、主要债权人停火函、应收A类清收启动 |
| 攻坚期 | 第 2—4 个月 | 收回应收 1,000 万以上；销售去化 1,500—2,500 万；落地首批以房抵债 |
| 重组期 | 第 3—6 个月 | 签署债务类型化协议或预重整协议；明确留债与抵债清单 |
| 收官期 | 第 7—12 个月 | 存货去化过半；负债降至可控；剩余留债按计划还款；信用修复 |

### 量化成功标准（建议写入内部考核）

1. 12 个月内现金回笼 + 抵债削债合计 ≥ **8,000 万**；  
2. 有息负债成本显著下降，逾期诉讼增量得到控制；  
3. 剩余存货与留债形成稳定匹配（每月销售回款可覆盖留债本息）；  
4. 不发生核心资产被低价网拍。

## 八、一张算账表（情景测算）

### 情景 A：顺利去化（基准）

| 项目 | 金额（万元） |
| --- | --- |
| 应收回收 | 1,800 |
| 存货销售现金 | 3,600 |
| 以房抵债削债 | 3,000 |
| 现金 + 削债合计 | 8,400 |
| 剩余留债 | 约 1,600—2,000 |
| 剩余存货货值 | 约 1,000—1,500 |
| 结果 | 盘面可稳住，转入正常经营清偿 |

### 情景 B：去化不及预期（压力）

| 项目 | 金额（万元） |
| --- | --- |
| 应收回收 | 1,200 |
| 存货销售现金 | 2,400 |
| 以房抵债削债 | 2,500 |
| 合计 | 6,100 |
| 缺口 | 约 3,900 |
| 动作 | 必须启动预重整/重整，推动更大幅度减免或引入接盘方 |

### 情景 C：被强制拍卖打穿（失败）

存货按货值 5.5—6.5 折处置，应收大面积坏账，清偿率显著下降，企业和股东被动性最差。  
**这是必须通过提前谈判避免的路径。**

## 九、当下就要做的 10 件事（执行清单）

1. 出存货清单（含抵押/查封状态）并分级；  
2. 出应收清单，按揭银行逐户盯办；  
3. 出债务清单，标出前十大债权人；  
4. 开共管账户，明确回款顺序；  
5. 向主要债权人发重组意向函，要 90 天停火；  
6. 制定 90 天去化价格策略（可售货值下浮区间）；  
7. 准备以房抵债房源包（权属干净、能过户）；  
8. 暂停非必要支出与关联清偿；  
9. 聘请律师做债权债务与诉讼保全体检；  
10. 若 30 天谈不成，准备预重整启动材料。
