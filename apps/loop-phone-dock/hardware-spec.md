# 硬件规格 v0.1（未制造）

目标：自己的备用机放进底座，摄像头看屏，执行器点按。敏感动作必须人确认。

## 机械

| 项 | v0 建议 | 原因 |
| --- | --- | --- |
| 运动 | CoreXY，X/Y 覆盖 6.9 英寸屏 | 和 Lumi 同思路，皮带精度够点图标 |
| 末端 | 软硅胶触头，压力可限 | 避免划屏；标定后限力 |
| 手机位 | 可换夹具 + 每次入位视觉标定 | 手机一动就停 |
| 头 | 单摄像头正对屏幕即可 | 双自由度云台留到 v1 |

## 电子

| 项 | v0 建议 |
| --- | --- |
| 计算 | 开发期用旁边的电脑；整机再上 RK3576 一类 6 TOPS 板 |
| 视觉 | 一颗全局快门或普通 USB 摄像头，固定焦距对屏幕 |
| 音频 | 先不做四麦；语音走电脑麦克风 |
| 充电 | 底座只供电，无线充电后置 |
| 急停 | 物理拔机 = 停；软件里也有取消 |

## 软件边界（和这套代码对齐）

1. 看屏：截图或虚拟 UI 树  
2. 规划：指令 → 目标坐标（以后换 PhoneUIAnchor 一类定位模型）  
3. 执行：`tap` / `swipe` / `type`  
4. 记忆：任务结果写成笔记，不默认上传  

发送、付款、删除在接真机之前保持「只规划、不自动执行」。
